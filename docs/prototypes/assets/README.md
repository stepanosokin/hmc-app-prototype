# Локальная подложка T22

`land.js` — только координаты полигонов из Natural Earth **v5.1.2**, слоя
`ne_110m_land` (1:110m). Свойства объектов удалены, геометрия сохранена.
Исходник: [GeoJSON в репозитории Natural Earth](https://github.com/nvkelso/natural-earth-vector/blob/v5.1.2/geojson/ne_110m_land.geojson).
Данные — [общественное достояние](https://www.naturalearthdata.com/about/terms-of-use/).
Авторы Natural Earth: Tom Patterson, Nathaniel Vaughn Kelso и участники проекта.

Береговая линия используется без государственных границ. Названия и координаты
нескольких городов внесены непосредственно в макет для ориентации. Шрифты системные,
значки авторские текстовые и SVG. Условное температурное поле вычисляется в макете и не является
метеорологическими данными. Ресурсы Windy не используются. Для работы макета сеть
не нужна; подложка загружается соседним локальным скриптом.

## Библиотеки расширения T24

В `vendor/` хранятся неизменённые браузерные сборки D3 Array 3.2.4,
D3 Geo 3.1.1 и proj4js 2.22.0. Версии и SHA256 совпадают с закреплёнными
в [технической проверке T23](../../../tools/display-projections/vendor-lock.json).
Они скопированы из проверенного локального кеша с проверкой SHA256;
при открытии страницы ничего не скачивается.

D3 отсекает береговую линию и покрытие по горизонту и границе 45° с. ш.;
proj4 выполняет прямое/обратное преобразование эллипсоидальной EPSG:3576.
Сферическая ортография использует R=6378137 м и параллельные лучи.
Поле, подписи и маркер используют ту же камеру. Высота равна нулю;
исходный GRIB и научный контракт этим демонстрационным макетом не меняются.

Оригинальные лицензии: [D3 Array](vendor/d3-array.LICENSE),
[D3 Geo, включая GeographicLib](vendor/d3-geo.LICENSE),
[proj4js](vendor/proj4.LICENSE.md). Источники лицензий:
[D3 Array v3.2.4](https://github.com/d3/d3-array/blob/v3.2.4/LICENSE),
[D3 Geo v3.1.1](https://github.com/d3/d3-geo/blob/v3.1.1/LICENSE),
