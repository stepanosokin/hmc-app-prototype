# Изолинии нативной сетки в браузере

29.10.2026 пользователь подтвердил построение изолиний на лету в фоновом
потоке браузера по нативным значениям Zarr и числовой маске, независимо
от интерполированной заливки. Это позволяет менять шаг и проекцию без
предрасчёта сервером всех комбинаций и сохраняет связь линий с числовым полем.
Растеризация цветов и выборка на экранную сетку не являются источником геометрии.

Существующий `native-display/3` читает нативные ячейки Zarr с halo и маской;
его float32-кодирование сохраняет объявленный допуск. Канонические point/EDR
и GIS не меняются. Поток изолиний получает копию одного блока за раз, сохраняя
владение буферами GPU-рендерера; память входа, рабочего графа, кеша и экранной
геометрии учитывается в общем бюджете 128 MiB. Устаревшие вычисления отменяются.

NoData исключает ячейки, допустимый ноль остаётся числом. Цвет и прозрачность
заливки не меняют построение. Экранная фильтрация, упрощение и сглаживание
не изменяют исходные значения. Для четырёх полей с неоднозначными единицами
применяются выбранные шаги исходных чисел с явной пометкой в легенде.

Давление в UI пересчитывается в гПа, удельная влажность в г/кг, высота снега
в см; это заменяет часть [ADR 0009](0009-field-value-validity.md) о единицах
отображения влажности, сохраняя исходные/API/GIS-единицы. Полные настройки:
[согласованные требования](../design/field-contours-discussion.md),
[задача №74](https://github.com/stepanosokin/hmc-app-prototype/issues/74).
