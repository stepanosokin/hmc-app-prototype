# Доказательства проверок хранятся отдельно от исходников

Полные архивы проверок перенесены из Git во внешний `HMC_EVIDENCE_ROOT`, чтобы
логи и повторные snapshots не увеличивали каждую загрузку исходников.
В `docs/validation/` остаются краткие результаты, ссылки и записанные хеши;
необходимые эталоны и проверочные программы сохраняются в отслеживаемых
каталогах. Это отделяет воспроизводимость обычной сборки от доступности
исторического архива, который нужно резервировать и передавать отдельно.
Старые Issues и история Git сохраняются. При переносе 26.10.2026 по указанию
пользователя проверки количества, размеров и хешей не выполняются; это
исключение не меняет требования к будущим проверкам.
