# Отбраковка ложных значений поля как NoData

На интервью 27.10.2026 согласовано: подтверждённо ложные значения считаются
[NoData поля](../../GLOSSARY.md) во всех представлениях. Они исключаются
из статистики и границ цветовой шкалы, прозрачны на карте и представлены
пропусками в точечных ответах и графиках; численные и GIS-продукты должны
использовать то же правило допустимости. Исправление только минимума шкалы
оставило бы ложные значения доступными потребителям.

Правила задаются отдельно для показателя с учётом единиц. Для абсолютной
температуры значения ≤ 0 K отбраковываются; температурные разности и аномалии
не являются абсолютной температурой. 0 °C остаётся допустимым. Произвольный
«нормальный погодный диапазон» не вводится. Для остальных показателей
дополнительная отбраковка применяется только после определения конкретного
правила; допустимые нули, в том числе нулевые осадки, сохраняются.

Если после отбраковки всё поле состоит из NoData, выбранный срок сохраняется,
интерфейс показывает «Нет данных» без цветовой шкалы. Исправление должно
охватить и уже опубликованные гриды с пересчётом масок, статистики и зависимых
продуктов.

Пользователь подтвердил итоговое понимание интервью 27.10.2026. Исходные
GRIB сохраняются; исходные пропуски и отбраковка различаются по причине и
счётчикам. Уже опубликованные поля заменяются новыми редакциями после
проверки производных; ошибка сохраняет прежнюю доступность. Устаревшие
редакции снимаются только при успешном переключении.

Дополнение пользователя 27.10.2026: допустимые нули показателей, кроме
абсолютной температуры, полностью прозрачны на карте, оставаясь числом 0
в статистике, точечных ответах и графиках. Это правило оформления, а не NoData:
численная маска и допустимость интерполяции сохраняются. Оно применяется
также к цветным производным и WMS, сохраняя численные значения GIS Identify.

Коды абсолютной температуры выбираются по идентификаторам GRIB2 и единицам,
а не по строке K: [таблица NCEP/WMO 4.2-0-0](https://www.nco.ncep.noaa.gov/pmb/docs/grib2/grib2_doc/grib2_table4-2-0-0.shtml)
различает температуру, её аномалию и дефицит точки росы. Условие положительной
температуры не распространяется на суммы, разности и стандартные отклонения.
