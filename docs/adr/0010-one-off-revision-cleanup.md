# Разовая очистка предыдущих редакций

Согласовано 28.10.2026 в интервью по задаче №70: отдельная команда
`hmc-app.mjs revisions` управляет редакциями независимо от загрузки GRIB.
`--keep-latest` сохраняет последнюю доступную редакцию каждого расчёта,
разово снимая предыдущие. Обычное истечение расчётов по сроку остаётся
отдельной операцией `--collect-apply`. Истёкшие и снятые данные не возвращаются.
У расчёта с доступной последней редакцией очищаются также старые недоступные
редакции. Расчёт без доступных редакций относится к обычной очистке по срокам;
ранее начатое физическое удаление предыдущих редакций может завершиться.

Режим не меняет постоянную политику: временная перенастройка с последующим
восстановлением опасна при сбое между этими действиями. Предварительный
просмотр и применение связываются идентичностью каталога, заданий, политики
и целевого стенда. Общие партии и активные чтения защищаются штатным сборщиком.
Физическая задержка разовой очистки записывается как долговечный срок по
обычным часам, чтобы фиксированные демонстрационные часы не блокировали её.

Применение требует подтверждения или `--yes`; `--dry-run` только показывает
план. Исходные GRIB сохраняются. Для этой задачи пользователь разрешил на
`hmc-app-live` только отчёт и предварительные просмотры; удаление проверяется
на отдельном стенде. Команды описаны в [ADMIN.md](../../ADMIN.md).
