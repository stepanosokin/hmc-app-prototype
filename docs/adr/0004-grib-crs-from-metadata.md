# CRS исходной сетки из метаданных GRIB2

Пользователь согласовал чтение параметров CRS отдельно для каждого сообщения
GRIB2 с приоритетом над единым файлом геодезических значений по умолчанию.
Это заменяет привязку обработки к одной фиксированной сфере, но сохраняет
различие исходной сетки, координат WGS84 и проекции отображения из ADR-0003.
Прежний `data/grib/proj.txt` не используется.

Согласованные умолчания: сфера радиусом 6 371 229 м, нулевой меридиан Greenwich,
нулевое геоцентрическое смещение к WGS84 как явно указанное прототипное
допущение. Параметры, заданные кодами и полями GRIB, имеют приоритет: значение,
определяемое стандартным кодом формы Земли, не считается отсутствующим.
Обязательные параметры объявленной проекции не восстанавливаются догадкой.
Файл с неподдерживаемой или повреждённой геопривязкой отклоняется с объяснением;
пакетная обработка остальных файлов продолжается.

Пересчёт охватывает только GRIB2 непосредственно в `data/grib`, без подпапок.
Формат определяется по содержимому, а не расширению. Пересчёт выполняется
в существующий `hmc-app-live` (интерфейс на порту 8140), с новыми редакциями
и сохранением прежних до проверки новых. Исторические свидетельства сохраняются.
Отсутствующий или некорректный файл умолчаний останавливает новую пакетную
загрузку; скрытых резервных значений в коде не будет, прежние публикации
остаются доступны.

Согласованы шаблоны GRIB2 3.0 (широтно-долготная), 3.1 (повёрнутая
широтно-долготная), 3.10 (Mercator), 3.20 (полярная стереографическая),
3.30 (коническая Ламберта) и 3.31 (Albers). Остальные шаблоны отклоняются
с объяснением согласно правилу неподдерживаемой геопривязки.
Итоговый план подтверждён пользователем 23.10.2026. Применённые умолчания и CRS
сохраняются с публикацией; исходные значения остаются в Zarr, числовой API
выбирает исходные ячейки. Для несовместимых ГИС-путей допускается явно обозначенный
производный COG. Порядок применения и файл конфигурации описаны в
[операторской документации](../grib-crs.md).
