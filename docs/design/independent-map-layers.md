# Независимый выбор фона и изолиний

Требования согласованы 25.11.2026 для [задачи №115](https://github.com/stepanosokin/hmc-app-prototype/issues/115). Карта позволяет, например, показать
температуру фоном и давление на уровне моря изолиниями для одного прогноза.

## Выбор полей

- Справа на карте две колонки иконок. Левая управляет изолиниями, правая фоном.
  В обеих одинаковые группы, иконки и порядок. Показатель и вертикальная
  поверхность или уровень выбираются независимо в каждой колонке.
- Показатели без поддерживаемых изолиний видны в левом меню как недоступные.
  Рядом объясняется причина, например отсутствие настроенного шага.
- В каждой колонке есть «Пусто». Этот вариант скрывает её слой и легенду.
  Когда обе колонки пусты, доступны базовая карта и отдельный слой ветра.
- При открытии карты исходный показатель выбран в обеих колонках, как при
  прежнем поведении с включёнными изолиниями. Кнопка «Изолинии» удаляется из
  условных обозначений фона.

## Общий прогноз

- Для двух слоёв общие модель, расчёт, редакция публикации и срок прогноза.
  Каждый слой использует данные своего поля ровно на выбранный срок.
- Шкала времени предлагает сроки общего расчёта, на которых доступно хотя бы
  одно из выбранных полей. Когда обе колонки пусты, шкала показывает все
  опубликованные сроки расчёта. Управление моделью, расчётом и сроком остаётся
  доступным.
- При выборе показателя текущий срок сохраняется, даже если для него нет
  данных ни в одной колонке. Легенда каждого выбранного поля без данных
  сообщает о пропуске. Поле с данными продолжает отображаться.
- При смене срока или расчёта сохраняются оба выбора, включая «Пусто».
  При смене модели выбор сохраняется для совпадающего показателя и уровня.
  Колонка без такого соответствия переходит в «Пусто».

## Условные обозначения и прогноз в точке

- У изолиний отдельная легенда с названием показателя, образцом линии,
  числовой шкалой с метками и текстом о шаге, например «Изобары проведены
  через 5 гПа». Шаг и единицы берутся из настроек изолиний выбранного поля
  для текущего масштаба карты.
- Шкала охватывает значения линий, пересекающих видимую область карты,
  включая линии без подписи. При нехватке места метки прореживаются. Если
  видимых линий нет, легенда показывает статус вместо шкалы и сохраняет
  текст с шагом, если он известен.
- Значение в точке, график и контекстная ссылка API относятся к фону, пока он
  выбран. Если для фона на выбранный срок нет данных, карточка точки сообщает
  об этом. При выборе «Пусто» для фона используется поле изолиний. Когда обе
  колонки пусты, значение в точке, график и контекстная ссылка API скрыты.

Это согласование заменяет решение об общем переключателе и месте вывода
шага в [прежних требованиях к изолиниям](field-contours-discussion.md).
