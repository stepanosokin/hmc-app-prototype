# Независимый выбор фона и изолиний

Исходные требования согласованы 25.11.2026 для [задачи №115](https://github.com/stepanosokin/hmc-app-prototype/issues/115). Карта позволяет, например, показать
температуру фоном и давление на уровне моря изолиниями для одного прогноза.
Последующие изменения описаны в [доработке интерфейса](#доработка-интерфейса-после-115).

## Выбор полей

- Справа на карте две колонки иконок. Левая управляет изолиниями, правая фоном.
  В обеих одинаковые группы, иконки и порядок. Показатель и вертикальная
  поверхность или уровень выбираются независимо в каждой колонке.
- Показатели без поддерживаемых изолиний видны в левом меню как недоступные.
  Рядом объясняется причина, например отсутствие настроенного шага.
- В каждой колонке есть «Пусто». Этот вариант скрывает её слой и легенду.
  Когда обе колонки пусты, доступны базовая карта и отдельный слой ветра.
- При открытии карты исходный показатель выбран в обеих колонках, как при
  прежнем поведении с включёнными изолиниями. Кнопка «Изолинии» удаляется из
  условных обозначений фона.

## Общий прогноз

- Для двух слоёв общие модель, расчёт, редакция публикации и срок прогноза.
  Каждый слой использует данные своего поля ровно на выбранный срок.
- Шкала времени предлагает сроки общего расчёта, на которых доступно хотя бы
  одно из выбранных полей. Когда обе колонки пусты, шкала показывает все
  опубликованные сроки расчёта. Управление моделью, расчётом и сроком остаётся
  доступным.
- При выборе показателя текущий срок сохраняется, даже если для него нет
  данных ни в одной колонке. Легенда каждого выбранного поля без данных
  сообщает о пропуске. Поле с данными продолжает отображаться.
- При смене срока или расчёта сохраняются оба выбора, включая «Пусто».
  При смене модели выбор сохраняется для совпадающего показателя и уровня.
  Колонка без такого соответствия переходит в «Пусто».

## Условные обозначения и прогноз в точке

- У изолиний отдельная легенда с названием показателя, образцом линии,
  числовой шкалой с метками и текстом о шаге, например «Изобары проведены
  через 5 гПа». Шаг и единицы берутся из настроек изолиний выбранного поля
  для текущего масштаба карты.
- Шкала охватывает значения линий, пересекающих видимую область карты,
  включая линии без подписи. При нехватке места метки прореживаются. Если
  видимых линий нет, легенда показывает статус вместо шкалы и сохраняет
  текст с шагом, если он известен.
- Значение в точке, график и контекстная ссылка API относятся к фону, пока он
  выбран. Если для фона на выбранный срок нет данных, карточка точки сообщает
  об этом. При выборе «Пусто» для фона используется поле изолиний. Когда обе
  колонки пусты, значение в точке, график и контекстная ссылка API скрыты.

Это согласование заменяет решение об общем переключателе и месте вывода
шага в [прежних требованиях к изолиниям](field-contours-discussion.md).

## Доработка интерфейса после #115

Согласовано 25.11.2026 для [задачи №116](https://github.com/stepanosokin/hmc-app-prototype/issues/116).
Эти требования обновляют порядок колонок, шкалу
условных обозначений изолиний и карточку прогноза в точке из задачи №115.

- Справа на карте две колонки. Слева выбор фона, справа выбор изолиний.
  Показатели без поддерживаемых изолиний видны в правой колонке и недоступны
  для выбора. Причина указана рядом.
- В условных обозначениях изолиний каждому значению линии, пересекающей
  видимую область карты, соответствует штрих на шкале. Штрихи расположены
  пропорционально значениям. Числовые подписи прореживаются при нехватке
  места, чтобы избежать наложения. Когда видимых линий нет, вместо шкалы
  отображается статус, а текст с известным шагом сохраняется.
- В заголовке карточки прогноза в точке значение фона слева, значение
  изолиний справа. Для каждого указаны показатель, вертикальная поверхность
  или уровень и единица измерения. На одном графике фон показан голубой
  линией, изолинии тёмно-серой. У каждого ряда свой вертикальный масштаб,
  обе вертикальные шкалы скрыты. При одном выбранном поле есть одно значение
  и одна линия цвета этого слоя. При совпадении показателя и уровня в обеих
  колонках показаны одно значение и одна голубая линия. Разные уровни одного
  показателя отображаются отдельно. Когда обе колонки пусты, значения и
  график скрыты.
- Два ряда совмещаются по общей горизонтальной оси UTC для одной точки,
  модели, расчёта и редакции публикации. Оба ряда используют числовые значения
  ближайших ячеек исходной сетки каждого поля. Сглаживание применяется при
  построении изолиний на карте. При отсутствии значения на выбранный
  срок у соответствующего поля в заголовке указано «Нет данных». На графике
  в этом ряду остаётся разрыв. Доступные значения ряда за другие сроки
  и ряд второго поля по-прежнему видны.
- При наведении на график видны время UTC и значения обоих показанных рядов
  в порядке заголовка, каждое со своей единицей или статусом «Нет данных».
  Явно выбрать на графике можно срок, на котором опубликовано хотя бы одно
  выбранное поле. В разделе «Ячейка и происхождение» сведения выводятся по
  каждому показанному полю при наличии данных. Ветровые флажки остаются одной
  полосой над общим графиком.
- В разделе «Источник и настройки» остаётся одна контекстная ссылка API.
  Она относится к фону, пока он выбран. При выборе «Пусто» для фона ссылка
  относится к полю изолиний. При двух пустых колонках ссылка скрыта.
