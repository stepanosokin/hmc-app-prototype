# Общий бюджет ресурсов карты

03.11.2026 пользователь поручил увеличить лимит после воспроизводимого отказа
изолиний на полноэкранной температуре при 1920×1080. Принято значение
256 МиБ по умолчанию вместо 128 МиБ. Затем пользователь поручил задавать
значение через `hmc-app.mjs`. Это заменяет прежнее ограничение в затронутой части
спецификации и ADR 0011; исторические измерения при 128 МиБ остаются прежними.

Значение по умолчанию задаётся единожды: `DEFAULT_MAP_RESOURCE_BUDGET_MIB` в
[`viewer/resource-budget.js`](../../viewer/resource-budget.js).
Эффективный `MAP_RESOURCE_BUDGET_BYTES` вычисляется из конфигурации проекта.
Его используют проверки общей памяти, загрузки/замены поля, readback,
GPU-слоя и ветра. Он доступен в диагностике как `managed_budget_bytes`.
Ограничения размеров текстур GPU и отдельные границы данных/кешей сохраняются.

Настройка: `node hmc-app.mjs viewer-budget hmc-app-live --memory-mib 512`.
Значение — положительное целое число МиБ без переполнения безопасного JS integer.
Оно сохраняется только для выбранного проекта, выводится в `status` и остаётся
при `start`. При первом подключении пересоздаётся только viewer; последующие
изменения требуют обновить страницу. Браузер получает только числовую
публичную настройку из `/build/viewer-config.js`; приватные настройки/секреты
не подключаются к просмотрщику. JS и данные GRIB не пересобираются ради значения.

Это управляемая оценка массивов, текстур, framebuffer, ветра, изолиний,
береговой линии, каталога и ряда, включая временные резервы. Она не равна
полной памяти процесса и не определяется объёмом VRAM видеокарты.
256 МиБ — выбранный бюджет прототипа, а не гарантия для произвольного
размера окна/DPR или обещание производительности. Проверка полноэкранного
ветра вместе с изолиниями обязательна для этой правки.
