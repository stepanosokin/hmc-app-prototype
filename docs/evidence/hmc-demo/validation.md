# Управление локальным демостендом — №42

[Задача №42](https://github.com/stepanosokin/hmc-app-prototype/issues/42).
Проверено 22.10.2026. Исходный HEAD:
`abe0031550d0655d1021f0a80712b77c1594bd59`.

Область: запуск, остановка и статус уже подготовленного `hmc-app-live`.
Первоначальная публикация, числовые алгоритмы и браузерный интерфейс не
менялись. Поэтому по таблице change-to-check выполнены Windows process check
и read-only Compose; T5 и браузерная матрица для этой категории не требуются.

Финальный [lifecycle.txt](checks/lifecycle.txt) подтверждает девять сценариев
на синтетическом Docker executable и локальном HTTP: остановленный статус,
запуск со ссылкой фактического порта, готовый статус, отказ остановки при
работающих сервисах, остановка, повторная остановка, отказ запуска при пустом
каталоге, недоступный статус и native exit 7. Журнал команд подтверждает
изоляцию проекта и отсутствие удаления данных. Полные потоки и результаты
хранятся в `lifecycle/`; ранний успешный прогон — в `development-pass/`.

Настоящий Compose проверен только чтением состояния. Первоначальная проверка
выявила пустую строку вместо пустого массива сервисов; исправление проверено
отдельным сценарием и повторным полным прогоном. Итоговый
[result.json](real-status-final/result.json) подтверждает `stopped`.
Неуспешная попытка сохранена в `real-status-before-fix/`.

Дополнительные проверки: [Windows process launcher](checks/process-check.txt)
(exit 0/7, аргументы и пути с пробелами, stdout/stderr),
[все 24 документа](checks/documentation-full.txt), синтаксис PowerShell,
`start/stop -WhatIf`, [официальный валидатор навыка](checks/skill-validation.txt).
Новый lifecycle check включён в Windows CI; удалённый CI здесь не заявляется.

Ранние попытки до изоляции fixture: HttpListener не стартовал (заменён TCP
listener); следующая попытка выявила кодировку дочернего stdout (исправлена
на UTF-8). Обе завершились с удалением собственного сервера и временного
каталога. Первые вызовы валидатора не выполнились из-за отсутствующего Python
trampoline/PyYAML; итоговая проверка прошла установленным Python через uv с
кешированным PyYAML. Эти ошибки подготовки не являются успешной приёмкой.

Ресурсы: [очистка подтверждена](cleanup.txt); тестовых Docker-проектов нет.
Пользовательский демостенд не запускался и не останавливался во время
валидации. Локальные credentials и исходный GRIB в архив не включены.

Обзор выполнен относительно исходного HEAD, включая новые файлы скрипта,
fixture, навыка, CI и документации. Исправления пустого вывода и кодировки
проверены до финального архива. SHA256 замороженных входов —
[inputs.json](inputs.json). Этот архив фиксирует фазу до коммита: задача ещё
открыта, push ожидается; финальные commit/push и закрытие проверяются в трекере.
