# Макет карты T22 и расширение T24

## Выборочные проверки

Для правки макета используйте существующий runner без Docker, сервера и сборки.
Новые параметры выбирают сценарий и один из его размеров экрана:

```powershell
# Показать объём без запуска браузера и создания файлов
node tools/check-weather-prototype.mjs --scenario=landscape --viewport=640x360 --plan

# Мобильное управление: только минимальный портретный экран и нужный снимок
node tools/check-weather-prototype.mjs --scenario=mobile-controls --viewport=360x740 --screenshots=focused-controls

# Горизонтальная компоновка: снимки начального вида и точки
node tools/check-weather-prototype.mjs --scenario=landscape --viewport=640x360 --screenshots=initial,point

# Проекции: существующие сценарии геометрии и взаимодействия на компьютере
node tools/check-weather-prototype.mjs --scenario=projections --viewport=1440x900 --screenshots=failure

# Итоговая полная матрица T24, включая прежние T22 и пять landscape-размеров
node tools/check-weather-prototype.mjs --projections
```

`base` проверяет прежние сценарии T22, `all` равнозначен `--projections`.
Портретная матрица: 1440×900 (мышь), 390×844 и 360×740 (touch).
Landscape: 1038×465, 844×390, 740×360, 667×375, 640×360; сценарий также
поворачивает выбранный экран в портрет и обратно. `mobile-controls` поддерживает
два портретных touch-размера. Несовместимые параметры завершаются до запуска
браузера. Старые `--projections --mobile-controls` и
`--projections --landscape-only` продолжают работать.

`--screenshots` по умолчанию равен `all`; `failure` сохраняет только ошибку,
остальные значения — фрагменты имён через запятую. Снимок ошибки сохраняется
независимо от фильтра. Любой фильтр экрана/снимков и отдельный сценарий T24
явно отмечены как Development (`selection.acceptance: false`); они не заменяют
полную приёмку. Для итоговой проверки используйте `--projections` без фильтров
в Chrome и Edge и независимую геометрию, если она входит в задачу.

`T22_CHROME` задаёт установленный Chrome/Edge. Без `T22_REPORT_DIRECTORY`
runner создаёт уникальный каталог внутри `data/reports/t22` или `t24`.
Если задаёте каталог явно, используйте новый для каждой попытки.
В `validation.json` записаны выбранная матрица, пропущенные снимки и
`timing_ms`: подготовка (Git и входы), запуск браузера, сценарии, очистка,
общее время. Это время инструмента проверки, а не скорость отрисовки приложения.
Каждый запуск закрывает свой браузер и удаляет профиль, включая неудачные.
Проверки параметров без браузера: `node --test tools/test-weather-check-options.mjs`.

## Выбор проекции — T24 / №36

Текущий файл дополнен для [T24 / №36](https://github.com/stepanosokin/hmc-app-prototype/issues/36).
Внешний вид, включая горизонтальный экран телефона, согласован пользователем 21.10.2026. Принятый архив T22 остаётся
неизменным; новые проверки и снимки хранятся [отдельно](../evidence/t24/validation.md).

Слева, непосредственно под описанием выбранного прогноза, расположен список
«Вид карты»: «Меркатор», «Глобус», «LAEA — Арктика (EPSG:3576)».
Глобус строго ортографический: вращайте его мышью или одним пальцем,
приближайте кнопками «+ / −». Стрелки сдвигают центр. LAEA фиксирована:
90° с. ш., 90° в. д., WGS84, нулевые смещения, севернее 45° с. ш.
Южная часть прогноза доступна в Меркаторе и на глобусе.

После замечаний пользователя от 21.10.2026 мобильные панели прогноза/проекции,
навигации, легенды и временной шкалы сворачиваются и при открытии закрыты.
Нажатие на строку с треугольником или Enter/Space раскрывает панель.
В компактном виде видны модель, время расчёта, вид карты, срок прогноза и
единицы. Для LAEA ограничение 45° остаётся видимым и при закрытой панели.
Шрифты и атрибуция доступны постоянно. На компьютере панели раскрыты.

Карточка выбранной точки открывается касанием карты. «⌄» сворачивает её,
сохраняя выбор; компактная кнопка «Точка» открывает её снова. «×» удаляет выбор.
Открытие панели прогноза сворачивает нижнюю карточку, освобождая настройки;
сам выбор и сообщения о невидимой точке сохраняются.

Переключение сохраняет расчёт, редакцию, срок, единицы и географическую точку.
За горизонтом, вне экрана или южнее области LAEA маркер скрыт, выбор и значение
сохранены, карточка объясняет причину. «К области данных» возвращает охват
видимого в данном режиме прогноза. При открытии всегда выбран Меркатор.
Если локальный преобразователь недоступен, выбранный вид остаётся недоступным
с объяснением и кнопкой явного перехода в Меркатор.

Это Canvas2D-макет с вымышленным полем. Путь T23 используется как основание
геометрии, но реальные тайлы, GPU, API и физический телефон здесь не проверяются.
Самописное перемещение в этом макете не моделирует инерцию и плавность рабочего
движка. Принятый технический путь T23 использует MapLibre GL JS 6.15.0 и
GPU-слой; ортографическое вращение обработано отдельно. Рабочий viewer #25/#27
ещё должен реализовать и проверить итоговое поведение жестов и инерции.
Все ресурсы лежат рядом с HTML; сервер, сеть и сборка не нужны.
Локальные библиотеки и лицензии описаны в [assets/README.md](assets/README.md).

Проверка T24: `node tools/check-weather-prototype.mjs --projections`.
Укажите установленный Chrome или Edge через `T22_CHROME`, а новый каталог
каждой попытки — через `T22_REPORT_DIRECTORY`. Сценарий включает прежние проверки
T22, mouse/touch, три вида, оба шрифта и обе подложки, горизонт и недоступный
преобразователь. Телефон эмулируется в размерах 390×844 и 360×740.
Он сохраняет точные входы, снимки и подтверждает удаление своего браузера/профиля;
Compose и серверы не создаёт. Независимая геометрическая проверка:
`python tools/check-weather-geometry.py <каталог>/validation.json` с pyproj/PROJ.

## Принятая основа T22

Откройте [weather-map.prototype.html](weather-map.prototype.html) двойным щелчком
или в Chrome/Edge через «Открыть файл». Сборка, сервер и доступ к сети не нужны.
Это отдельный демонстрационный макет для [задачи №34](https://github.com/stepanosokin/hmc-app-prototype/issues/34),
а не рабочая карта с метеоданными.

На компьютере модель, поле и расчёт находятся слева сверху, слой справа,
температурная шкала справа над временной панелью, значение рядом с точкой.
Панели уменьшены; фон каждой панели и кнопок имеет 90% прозрачности
(непрозрачность фона 0,10). Текст и значки остаются непрозрачными.
Синие акценты `#1250a5`, `#00aced` и светлый `#cef2ff` взяты за ориентир из
[палитры meteoinfo.ru](https://meteoinfo.ru/templates/jm-hot-news-ef4/css/template.9.css).
Компоновка, тёмное стекло и локальные авторские значки сохранены.
Слой обозначен термометром; название появляется при наведении мыши или
клавиатурном фокусе, а доступное имя сохраняется для экранного диктора.
Отдельный виджет «Модель» отделён от типа данных, поля и расчёта и остаётся
видимым при закрытых настройках. В этом макете доступна только ICON-EU;
другие модели и типы данных не имитируются.
На телефоне точка и настройки используют одну нижнюю панель, которая сначала
свёрнута. По умолчанию время расчёта и прогноза показано в UTC.
Список «UTC / Местное» в заголовке временной панели переключает все подписи
времени на часовой пояс системы пользователя и обратно. Обновляются даты,
расчёты, сроки, демочасы, график, подсказки и подробности подключения. Смещение
UTC явно указано; в настройках виден системный часовой пояс. Модель, редакция,
точка, срок и значения сохраняются; время в API-ссылках остаётся в UTC.
Выбор сбрасывается при перезагрузке. Подписи городов отрисованы с мягкой тенью,
без контурной обводки, создававшей угловые выступы у букв.

Для просмотра оформления:

1. Сравните исходный вид на компьютере и телефоне. Кнопками «+», «−», «←», «→»
   измените охват; «К области данных» восстановит его с той же выборкой.
2. Нажмите на карту. На компьютере значение появится у маркера, на телефоне —
   в нижней панели. Маленькая квадратная кнопка «×» (24×24 px) в правом верхнем
   углу карточки или панели убирает значение вместе с маркером. Она не занимает
   отдельную строку и имеет доступное имя «Закрыть значение точки». Клавиша Escape также закрывает
   точку. После закрытия можно снова нажать на карту. Смена срока очищает предыдущую точку.
3. В «Источник и настройки» выберите расчёт или единицы. По умолчанию выбран
   новейший пригодный демонстрационный расчёт 06:00 UTC и первый срок 07:00 UTC.
4. Для расчёта 06:00 выберите срок +3 ч: редакция 1 его не содержит. В настройках
   нажмите «Имитировать новую редакцию». Срок остаётся отсутствующим, пока явно
   не нажата кнопка «Принять обновление». Она сохраняет расчёт/срок и очищает точку.
5. «Имитировать сбой обновления» показывает ошибку с сохранением опубликованной
   выборки. Кнопка «Свернуть» закрывает подробности. Перезагрузка сбрасывает демо.

Поле, значения, полнота, расчёты и публикации вымышлены. Фиксированные демонстрационные
часы — **15.10.2026 07:00 UTC**; возраст рассчитывается относительно них. Это
температура на условной закодированной поверхности, а не воздух на высоте двух
метров. Числовой API, нативная сетка, реальная публикация, GPU и достоверность
температур этим макетом не проверяются. Подложка и права описаны в
[assets/README.md](assets/README.md). Все ресурсы локальны; используются системные
шрифты и авторская температурная палитра.

Слева внизу под временной шкалой расположен небольшой список шрифтов,
оформленный как подпись подложки справа. «Системный» возвращает исходный шрифт,
«Courier New» меняет шрифт всей страницы, элементов управления и подписей карты.
Выбор действует до перезагрузки; файлы шрифтов из сети не загружаются.

Перед списком шрифтов стоит видимая подпись «Шрифт:». В подпись справа встроен
список «Подложка: Natural Earth · тёмная / светлая». Это два оформления одной
локальной географической подложки, без дополнительных провайдеров или сетевых
запросов. Выбор меняет цвета воды, суши, береговой линии и городских подписей,
сохраняя погодное поле, выбранные расчёт/редакцию/срок/точку и масштаб карты.
Источник Natural Earth указан в обоих вариантах; перезагрузка возвращает тёмный.
На светлой подложке текст и подписи графика темнеют для читаемости; прозрачность
фона панелей остаётся 90%.

Карточка точки содержит минималистичный график температуры: светлая сплошная линия —
прошлое, синяя пунктирная — прогноз закреплённого расчёта, вертикальная отметка
«сейчас» — фиксированные демонстрационные часы 07:00 UTC. Обе части вымышлены,
включая историю: это не наблюдения. Пропущенные сроки прогноза оставляют разрыв,
выбранное значение обозначено точкой. Наведение на значения показывает время и
температуру в отдельной подсказке, вертикальная направляющая отмечает выбранный
час. Наведение между значениями выбирает ближайший срок; на пропуске показывается
«Нет срока». Подсказка скрывается при уходе указателя; на телефоне можно коснуться
графика, с клавиатуры — выбрать график Tab и использовать стрелки.
Единицы и шрифт согласованы с выбранными на странице.
За пределами покрытия или при отсутствии выбранного срока график недоступен.
Расчёт и происхождение значений раскрываются через «Расчёт и источник».

В «Источник и настройки» добавлены ссылки WMS и API для выбранной редакции.
WMS — адрес GetCapabilities закреплённого расчёта/редакции для подключения клиента,
API — запрос значения точки с точным сроком, полем T_G и координатами.
При отсутствии выбранной точки используется явно подписанный пример в центре
покрытия. Ссылки меняются после явного принятия новой редакции, выбора расчёта,
срока или точки. Это демонстрационные адреса на `demo.invalid`, не работающие
сервисы; идентификаторы вымышлены, ключей в URL нет. Исходные единицы API — K.

Проверка из корня репозитория: `node tools/check-weather-prototype.mjs` (Node.js
с глобальным WebSocket и установленный Windows Chrome). Другой путь к Chrome/Edge
можно задать переменной `T22_CHROME`. Скрипт запускает собственный скрытый браузер,
работает с видимыми элементами управления через CDP, сохраняет снимки и проверяет
закрытие процессов и удаление своего профиля. Он не закрывает пользовательские
окна браузера. Новые результаты записываются в игнорируемый `data/reports/t22`,
сохраняя принятый архив в `docs/evidence/t22`. Для отдельной попытки можно задать
`T22_REPORT_DIRECTORY`; выбирайте новый каталог, чтобы сохранить предыдущий результат.

## Горизонтальный экран телефона

При высоте до 600 px в горизонтальной ориентации действует компактная раскладка независимо от ширины. Группы закрыты по умолчанию; одновременно раскрывается одна группа. Карточка точки расположена справа и прокручивается. Раскрытие другой группы скрывает карточку, сохраняя выбранную точку. Поворот экрана сохраняет прогноз и точку. Проверяются размеры 1038×465, 844×390, 740×360, 667×375 и 640×360. Отдельная проверка: `node tools/check-weather-prototype.mjs --projections --landscape-only`.
