# Ретроспектива реализации №47

Основание — текущая сессия, [проверки и ошибки запуска](wms-compat/checks.json),
[приёмка и live rollout](wms-compat/validation.md),
[review](wms-compat/review.md) и коммит
[3123c7f](https://github.com/stepanosokin/hmc-app-prototype/commit/3123c7f145e621433842005ae661960007b54934).
Это отдельная ретроспектива после реализации; [№47](https://github.com/stepanosokin/hmc-app-prototype/issues/47)
остаётся закрытой. Исторический архив задачи сохраняется побайтно.

1. **Приёмка реального клиента — главный риск.** Прежний helper задавал
   dpiMode=0, maxWidth/maxHeight=512 и IgnoreGet*; успешный тест не доказывал
   работу обычного подключения. В №47 это уже исправлено, включая Identify
   на одном слое после смены времени. [QGIS workflow](../development/qgis.md)
   теперь задаёт явный критерий такой проверки и различает изображение GetMap
   и виртуальный canvas GetFeatureInfo. Повторное закрепление URI времени
   не заменяет пользовательский сценарий. Дополнительные тесты не создавались.

2. **Готовая проверка вне локального запуска.** В
   [check-local.ps1](../../tools/check-local.ps1) были T13/T25 и общие проверки,
   но отсутствовал готовый [WMS verifier](wms-compat/verify.mjs). Подключён его
   существующий resource-free режим к Windows/All. Он проверяет 402 артефакта,
   240 замороженных копий, итоговую приёмку, retirement, два разных срока и
   сохранность live-каталога в записанных результатах. Без `--current` архив
   проверяется независимо от дальнейших правок исходников. GitHub Actions
   и новый фреймворк не нужны.

3. **Экономия неудачных команд.** Предположенный mypy.ini отсутствовал;
   строка путей через native PowerShell стала одним путём; обёртка @(...)
   вокруг ConvertFrom-Json дала вложенный массив и остановила rollout до
   перезапуска. [Acceptance guidance](../development/acceptance.md) направляет
   к реальному Compose/CI-вызову mypy; [service guidance](../development/services.md)
   содержит рабочие формы массивов и JSON inventory. Это ошибки разовых команд,
   а не новый синтаксический стандарт приложения; отдельный линтер или тесты,
   дублирующие поведение PowerShell, не добавлялись.

Просмотрены существующие package scripts, Compose typecheck, локальный wrapper
и manual CI. Автоматический pre-commit hook не настроен, CI запускается через
workflow_dispatch; это остаётся ограничением автоматического запуска проверок.
В этой ретроспективе подключён пропущенный детерминированный вызов к принятому
локальному пути. Автоматические hooks/CI-триггеры не включались.

Изменены профильные инструкции, локальный wrapper и список документов проверки
ссылок. AGENTS.md уже направляет к этим инструкциям; глобальные правила,
сторонние skills и продуктовый WMS-код сохраняются. Проверки и отсутствие новых
Docker/QGIS/browser ресурсов записаны в [retro-wms-compat-checks](retro-wms-compat-checks).
Сохранён пользовательский hmc-app-live; ретроспектива его не перезапускает.
