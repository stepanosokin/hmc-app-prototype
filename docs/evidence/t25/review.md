# Обзор T25

Начальный коммит: `6e76858eaca12dbfc8a722f141896024d1520610`.
Обзор незакоммиченных изменений выполнен по `code-review`, двумя
независимыми агентами Standards и Spec; промежуточных коммитов нет.

## Standards

Исправлены: очистка первоначального слоя при отказе/таймауте подготовки;
очистка принадлежащих этой попытке массивов и метаданных; полная идентичность
показанного расчёта/редакции/срока; удаление неиспользуемых staging-владельцев.
Скачивание, декодирование и будущая GPU-текстура резервируются в общем бюджете;
отмена освобождает накопленные блоки. Общая подготовка слоя используется и
сменой срока, и явным обновлением публикации.

## Spec

Исправлены: общий обработчик HTTP 410 для точки при смене проекции;
восстановление географического контекста после WebGL loss при пропуске;
возобновление выбранного срока после изменения проекции во время загрузки.
При перестроении скрытое поле после пропуска/истечения остаётся скрытым;
первый кадр включается только после полной подготовки. Повторный статический
обзор обеих осей не выявил новых существенных замечаний.
Сценарий дополнен кнопками времени, ползунком, проверками отсутствия повторных
запросов контекста и суммарного бюджета управляемых ресурсов.

Повторный обзор последних исправлений по обеим осям не обнаружил новых
существенных дефектов (Standards: 0; Spec: 0). Проверены подтверждение
отменённых локальных CDP interceptions без ослабления блокировки внешних
зависимостей, компактные состояния времени и размещение уведомления.
Шесть новых локальных тестов проверяют положительные и отрицательные
случаи сетевого перехватчика; запуск добавлен в CI.

Визуальный обзор реального Android выявил перекрытие начала ошибки кнопкой
возврата к точке. Исправление разносит элементы, пересчитывает размещение при
смене шрифта и добавляет проверку прямоугольников для системного шрифта и
Courier. Снимок `android-status2` просмотрен: сообщение полностью читается.
Результаты окончательной приёмки: [validation.md](validation.md).
