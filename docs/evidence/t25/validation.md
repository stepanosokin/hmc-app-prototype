# T25 — смена срока без пересоздания карты

Задача: [№39](https://github.com/stepanosokin/hmc-app-prototype/issues/39).
Начальный коммит: `6e76858eaca12dbfc8a722f141896024d1520610`.
Архив до единственного коммита; окончательное состояние GitHub и remote HEAD
проверяются после push и сообщаются при передаче результата.

## Поведение

Существующие select, ползунок и кнопки времени используют одну транзакцию.
Карта, локальный контекст, подписи, камера, точка и состояние панели сохраняются.
Point API заново получает число закреплённой выборки. Поле готовится в скрытом
слое и включается целиком без анимации. Старый кадр подписан собственными
расчётом, редакцией и временем; запрошенный срок имеет отдельное состояние.
Пропуск и HTTP 410 скрывают поле и число. Ошибка доступного срока сохраняет
только подписанный прежний кадр; ошибка видна и в свёрнутой шкале телефона.

Последовательные выборы отменяют старые запросы и GPU upload. Подготовка общая
для смены срока и явного обновления публикации. Кеша кадров нет. До скачивания
резервируется ограниченный массив, будущая текстура и decode scratch в общем
бюджете 128 МиБ; учитываются существующие массивы/текстуры, canvas и framebuffer.
Отмена очищает накопленные блоки и удаляет промежуточную текстуру.

## Свидетельства и очистка

Каждая Compose-попытка сохранена в `attempts/`: исходный artifact index,
retirement receipt и полный снимок `reports/inputs`. Все длины/SHA256 исходного
архива проверяются до копирования. Входы сверяются с inputs-start; итоговые
inputs-end должны совпадать. У dev4/dev5 сохранены неуспешные preflight;
они не считаются runtime-приёмкой. Корневой `artifact-index.json` содержит
длины, SHA256 и ожидаемые Git blob всех файлов архива, кроме самого индекса.
Сырые снимки сохраняют исходные байты через `.gitattributes`.
Проверка: `node docs/evidence/t25/verify.mjs`; перед коммитом добавляется
`--staged`. Проверяются архив, retirement, все исходные снимки и итоговые
замороженные входы; для изменённых исходников требуется совпадение raw Git blob,
для неизменённых сохраняются существующие правила checkout из начального коммита.
Проверка whitespace исключает только `attempts/**/reports/inputs/**`, где
сохранены прежние исходники; изменённый код и описания проверяются полностью.

Resource-free проверки не создавали Docker/browser ресурсов; локальные логи
сохранены в `checks/`. Исходный неудачный тест сетевой fixture также сохранён:
undefined requestId ошибочно совпадал с отсутствующим failId; исправление
затрагивает только fixture. Пробы range/CDP сохраняют собственные cleanup receipts.
[Окончательная инвентаризация](checks/final-cleanup.json) подтвердила очистку
19 проектов: контейнеров, сетей и томов не осталось. Тестовые профили/вкладки,
ADB mappings, сервер 5041, временный SDK, созданные этой задачей неизменённые
ключи и файлы тестовых паролей удалены. Live stacks не сохранены; пользовательский
Chrome, исходники, исторические свидетельства, общие образы/кеши и посторонние
проекты сохранены. Список просмотренных снимков: [visual-review.json](checks/visual-review.json).

Сверка staged bytes выполняется `verify.mjs --staged` после добавления файлов
и повторяется на окончательном индексе перед единственным коммитом. В архиве
сохранён предкоммитный снимок трекера; push и закрытие проверяются живым
чтением после публикации, без изменения уже зафиксированного архива.
