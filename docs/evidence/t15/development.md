# История проверок T15

Все попытки используют отдельные Compose volumes и явные часы
`2026-10-19T05:00:00Z`. Обычный просмотрщик показывает реальные продукты;
`validation=1&fixtures=1` явно разрешает подписанные перекрывающийся расчёт
и коррекцию +1 K. Они дополняют исходный GRIB, не заменяя его проверку.

| Попытка | Результат |
| --- | --- |
| dev1 | Воспроизведена ошибка: принятие редакции переключало другой расчёт и сбрасывало срок. |
| dev2 | Первый целевой сценарий прошёл: расчёт и срок сохранились, GPU identity сменился. |
| dev3 | Реальные сбои API и отмена fetch/decode/upload прошли; драйвер пытался выбрать Москву вне экрана после смены проекций. Перед кликом добавлен явный fit. |
| dev4 | Принятие на повёрнутом глобусе, отказ GPU, context loss, gap refresh и повторные замены прошли. Драйвер не ждал создания evidence API после новой навигации. Исправлено ожидание. Перехват requestAnimationFrame теперь сохраняет семантику cancelAnimationFrame, чтобы не запускать отменённый MapLibre render после удаления карты. |
| dev5 | Полный целевой desktop-сценарий прошёл; 6387 GPU-сэмплов, ошибка ≤0,001740 K, маски совпали; реальный EDR/WMS совпал с point. |
| android1 | Нативные действия и первые гонки прошли; драйвер пытался нажать refresh в панели, закрытой сменой проекции. Исправлено открытие настроек перед проверкой. |
| android2, android3 | Принятие, GPU loss и gap refresh прошли. Повторные переключения выявили расширение viewport с 384 до 460 px и ошибочные касания. Исправлены ширины вкладок, кнопка сворачивания, переполнение панели, обрезка карты и фиксированная область приложения. |
| android4 | Viewport сохраняет 384×694 и нулевой сдвиг. Драйвер продолжил сценарий до фактического изменения native select. Теперь он различает настоящие native options и ожидает завершающий click и выбранный индекс. |
| android5 | Целевой физический сценарий прошёл: 5915 GPU-сэмплов, ошибка ≤0,001754 K, маски совпали, point/EDR/WMS согласованы; переходы панели и повторные замены прошли. |
| final1 | Полный Chrome прошёл. Edge выявил утечку унаследованных реальных сроков из смешанной тестовой редакции в публичный каталог. Редакция теперь исключается целиком; в validation-режиме пометка тестовой коррекции сохраняется независимо от порядка сроков. Новый экспортный тест сначала воспроизвёл ошибку, затем прошёл. |
| android-final1 | Полный физический gate прошёл, но после исправления каталога приёмка повторяется на общих замороженных входах final2. |
| final2 | Полная Chrome/Edge матрица, T14 регрессия, T15 обновления/отказы/гонки, числовые сравнения, unavailable mode и Python discovery прошли. Входы 178 файлов start/end совпали; стенд архивирован и удалён. |
| android-final2 | Полный физический gate и числовые сравнения прошли на тех же 178 входах. Вкладка/перенаправления/UI dump удалены, пользовательский Chrome сохранён; стенд архивирован и удалён. |

Архивы попыток содержат исходные отчёты, входы и retirement receipts.
Каждый receipt и исходный индекс проверены перед копированием; недостающие
расширения полных входов восстановлены из start snapshot с проверкой SHA256.
Неудачные попытки остаются Development evidence и не используются как полная приёмка.

Первые Node/TypeScript/mypy проверки прошли; mypy проверил все 67 исходных
файлов на тот момент. Ресурс-свободные Node/TypeScript проверки стендов не
создавали; временный mypy container запускался с `--rm`. Итоговые команды,
новые входы и результаты сохраняются отдельно после завершения review.
