# Локальная приёмка №47

Все функциональные критерии выполнены. Это снимок **до коммита/push/закрытия**;
статус GitHub в `tracker-pre-commit.json` отражает именно этот этап.

- Development T11 `hmc-publication-t11-compat47dev`: обе фазы прошли, включая
  QGIS Desktop 3.44.11-Solothurn, HTTP-сверку, T8 policies, общую suite/runtime.
  Сохранены 120 точных входов. Retirement `099ec7ce32204620873c86952b6b6550`.
- Выбранная окончательная приёмка `hmc-publication-t11-compat47accept`: полный
  двухфазный T11 на неизменных 120 входах, T5 (28 редакций), T8 policies,
  перезапуск и повторный WMS, runtime; suite: 50 тестов, 28 выполнены,
  22 условных сценария пропущены с явными причинами. Retirement
  `bce919c57cfd471d944e0c15c330ac01`. Отдельно выполнены два unit-теста и mypy;
  CLI-ошибки запуска и их исправления сохранены в `checks.json`.
- Настоящий QGIS: обе CRS, два разных срока одной сохранённой редакции,
  20 числовых проверок границ/центра/NoData; окно 1204×700 автоматически
  разбивается без dpiMode/maxWidth/maxHeight/IgnoreGet* в URI. На том же слое
  без URI time настоящий Identify дал 280.69244384765625 K и
  280.6483154296875 K в обеих CRS. Легенды получены; PNG визуально проверены.
- T11 проверяет DPI с неизменными PNG, default TIME карты и Identify,
  большой контекст 1205×525, неправильные размеры/пиксели/BBOX/format options,
  меньшую политику 32×32 и невозможность повысить её клиентским заголовком.
- Live: после проверки владельца перезапущены только API/gateway. Первая
  защитная проверка остановилась до перезапуска из-за вложенного массива
  PowerShell; повторное чтение/разворачивание массива подтвердило пять сервисов.
  Остальные сервисы не перезапускались, тома не пересоздавались, задания
  публикации не запускались. Сравнение каталога:
  300 записей, SHA256 `46dc902de85a798f345499f547d1145033358e70528e788a0e8a2e3894834800`
  до и после; редакция с 24 сроками сохранена. Исходный live repro теперь проходит.
- Публичная ссылка через viewer проверена дополнительно в настоящем QGIS:
  карта и Identify на сроках 01:00/10:00 UTC совпали с API —
  280.6483154296875/286.7913513183594 K. Состав пользовательских слоёв не изменился,
  проект не сохранялся. Свидетельства — `live-desktop.json` и два PNG.

Браузеры не запускались, новые device/GPU/performance утверждения не делаются.

контейнеров, сетей и томов нет; одноразовых check-контейнеров не осталось.
