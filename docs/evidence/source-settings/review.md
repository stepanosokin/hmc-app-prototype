# Review №46

Сравнение с `15d815e68769633e1c0ac0ab12175cc6477f765a` выполнено перед итоговой
приёмкой. Изменения разделены по существующим границам: каталог сообщает `wms`,
`SourceSettings` выводит запрошенный контекст, viewer bridge транспортирует
уже разрешённый публичный scoped WMS в существующий gateway.

- UI не сериализует collection JSON. Полный документ доступен отдельной ссылкой;
  короткая редакция не используется как идентификатор запроса.
- Ссылки не строятся из удержанного кадра. Missing/expiry, pending selection,
  отсутствие точки и старое description рассмотрены отдельно. Имя исходного
  файла не выводится из несовпадающего по редакции/сроку ответа.
- Нового origin/configuration, общего reverse proxy, ключей в браузере и
  изменений authentication, accounting, storage/publication или GIS contracts нет.
  Сохраняется прежний bounded public-only transport. Поэтому повтор T5/T8/T11
  и физического QGIS не требуется: новые реальные HTTP-проверки проходят через
  gateway/GeoServer и проверяют GetCapabilities/GetMap, а две unit checks —
  фиксированный host, отсутствие пересылки credentials и запрет private paths.
- Scope UI покрыт существующим локальным браузерным runner: четыре размера,
  оба шрифта/подложки, Chrome/Edge, действительные URL, clipboard, смена
  редакции/срока/точки, пропуск и явные synthetic loading/503/410.
- Review поправил предположение браузерной проверки о наличии +2 ч gap:
  теперь gap выбирается по реальным options, чтобы не ломать T27 с 24 сроками.
  Метаданные дополнительно снимаются отдельным скриншотом.
- Дополнительный review исправил подпись удерживаемого кадра: сравнивается
  selection identity, а не строки времени (`Z`/`.000Z` могли отличаться при
  равном UTC). При ожидании другой редакции того же срока теперь отдельно
  названы фактически показанные расчёт, срок и редакция. Адресный DOM replay
  подтверждает отсутствие старой revision в прежней подписи и присутствие
  после исправления; полный browser gate повторяется на новых frozen inputs.
- Неизменённые научные допуски, память/GPU и samples не ослаблены. Сценарий
  настроек завершает отдельную навигацию страницы перед прежними регрессиями;
  server caches уже прогреты этой проверкой, новых cold-performance claims нет.

Итоговый полный gate запускается на замороженных входах после этих исправлений.
Мобильные viewport — эмуляция, не новое утверждение о физическом Android/iOS.

Одноразовый revision probe первоначально получил искажённую кириллицу в assert
через PowerShell stdin. Его первые статусы failure не используются как
самостоятельное доказательство дефекта: сохранённые DOM snapshots отдельно
сравнены по фактическому имени редакции, а исправленный probe с Unicode escapes
и проверкой revision прошёл. Профили всех этих попыток удалены, процессов 0.
