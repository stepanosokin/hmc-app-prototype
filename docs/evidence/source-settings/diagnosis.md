## Воспроизведение и причина

Изолированный Chrome открыл живой `localhost:8140`, дождался поля и открыл
«Источник и настройки». Проверка упала `Settings must contain WMS URL`;
текст `metadata` содержал **8711 символов**. Снимок и report сохранены в `before/`.
Профиль удалён, остаток браузерных процессов 0; Docker-ресурсов проба не создавала.

Причина установлена непосредственно по DOM и коду: в рабочем HTML отсутствовал
блок connectionLinks согласованного макета; `selectionDetails()` выводил весь
collection response через `JSON.stringify(metadata)`. Это прямой дефект
комплектности UI, поэтому отдельные инструментальные гипотезы не требовались.
Дополнительно каталог уже возвращал scoped `wms`, но viewer bridge не разрешал
`/gis/...` и ссылка на том же origin возвращала бы 404.

## Реализация

`SourceSettings` владеет читаемыми полями, ссылками и clipboard. WMS берётся
из каталога, закрепляет run/revision и открывает GetCapabilities. Point API
задаёт selection/run/revision/exact time/layer/coordinates/CRS84; значения — K.
Пример центра native coverage переводится в географическую широту тем же
преобразованием, что используется в viewer, и явно подписан. Без готового
покрытия при loading/error пример не выдаётся за текущую точку. При missing
нет API/metadata URL, WMS редакции остаётся; expiry убирает все URL.

Прежний отображаемый кадр подписывается отдельно; сведения файла берутся только
из описания совпадающей редакции и срока. Смена/удаление точки обновляет URL;
асинхронное копирование не выдаёт уведомление для уже изменённого адреса.
При недоступном clipboard выделяется readonly поле для ручного копирования.

Viewer разрешает только существующий scoped публичный WMS path по тому же
фиксированному gateway с прежними ограничениями 4 МиБ, timeouts и запретом
redirect. Browser headers/cookies/organization keys не пересылаются. Организационный
`/org`, unscoped GIS, GeoServer admin и произвольные hosts не разрешены.

## Первые статические проверки

Начальная сборка выявила ошибку вызова `nativeToWgs`: существующая функция
принимает широту, а не пару координат. Вызов исправлен; TypeScript/build passed.
`npm.cmd` отсутствует в PATH; те же существующие 12 viewer tests запущены
напрямую через `node --test --test-isolation=none 'viewer/test-*.mjs'` — 12/12.
Эти попытки ресурсов не создавали. Две bridge unit checks и mypy выполнены
в имеющемся Docker image с `--rm --network none`; контейнеры одноразовые.

Новые термины и ADR не нужны: UI следует уже принятым понятиям model run,
publication revision и exact nearest-native-cell query.
