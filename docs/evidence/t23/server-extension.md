# T23a — Числовая доставка для новых проекций в пределах допуска 0,01 K

Связана с #35 (T23); должна быть проверена до рабочей карты #25/#27.
Контракт `hmc-temperature-tile/2` и его исторические свидетельства не изменяются.

## Основание

В техническом эксперименте T23 на реальных ICON-EU T_G тайлах через Compose
gateway дополнительная билинейная интерполяция существующих f32-тайлов дала
максимальную ошибку 2,558872628 K относительно независимого билинейного
эталона из исходного GRIB в той же географической точке. Ошибка кодирования
в центрах проверенных пикселей составила 0,000015252109 K; проверенные halo
совпали. Это отвергает проверенный способ повторной интерполяции v2,
а не все возможные браузерные способы отображения.

Нужен проверенный способ получить числовое поле для строгой сферической
ортографии и WGS 84 / North Pole LAEA Russia EPSG:3576. Рассмотреть доставку
исходных нативных ячеек с halo для однократной интерполяции на GPU и серверные
производные отображения с доказанным общим бюджетом ошибки. Выбор пока не сделан;
новая версия контракта требует явного утверждения и не возникает из этого issue.

## Критерии приёмки

- [ ] Сравнены применимые варианты на реальном образце через gateway, с независимым GRIB-эталоном в тех же экранных/географических точках; отдельно сохранены неудачные способы. Суммарная ошибка ≤0,01 K, ошибка кодирования ≤0,001 K; COG ≤0,0001 K остаётся отдельным пределом.
- [ ] Утверждён и версионирован новый контракт числового отображения: URL/metadata, версия, CRS и смысл координат, идентификатор/параметры matrix, origin, orientation, размер/halo, маски, interpolation, bounds и native sphere/WGS84 operation с высотой 0. v2 доступен и не переопределён.
- [ ] Для EPSG:3576 поле, локальная подложка, подписи, граница покрытия и маркер используют согласованную геометрию; показ ограничен 45° с. ш. по-русски. Новых обещаний внешнему WMS/QGIS нет.
- [ ] Ключи кеша включают версию/matrix/CRS/параметры сетки/engine и полную immutable selection; готовы representative readiness probes, ограниченные generation/cache/decoded/GPU ресурсы. Смена режима не меняет selection или смысл point/EDR.
- [ ] Gateway проверяет eligibility/access/retention до кеша, корректно учитывает бюджеты, отмену, таймауты и output limits. Point API остаётся каноническим nearest-native-cell; отображение не использует point API как неограниченный загрузчик растра.
- [ ] Выполнены необходимые T5/T6/T7/T8/T9/T10/T12 регрессии по фактическим категориям изменений; desktop QGIS только при соответствующих изменениях сервиса/контракта. Реальный GPU и Android/iOS остаются отдельными gate, эмуляция их не заменяет.
- [ ] Проверены маски, границы покрытия, halo/стыки и явно синтетические полюс/±180°/горизонт/отсечение. Архивированы входы/хеши, версии, команды, положительные/отрицательные результаты и review; выполнен retirement каждой попытки с нулевыми ресурсами.

## Бюджеты, подтверждённые пользователем в T23

Desktop Chrome/Edge: p95 кадра ≤33 мс. Mobile Chrome/Android и Safari/iOS:
p95 ≤50 мс. Холодный первый показ ≤3 с, тёплый ≤1 с; числовая передача
≤8 МиБ на вид; декодированные массивы и GPU-текстуры ≤128 МиБ.
Эти цели согласованы, но данным экспериментом не подтверждены.

Движок MapLibre и требование строгой ортографии сохраняются. Новые поля,
ветер, временное смешивание и миграция GRIB/Zarr/COG не входят в эту задачу.
