# Review продолжения T23

Основание: `e7f6722c638d7cc77611eb0ef4ef29bbe64ca2a7`, незакоммиченные
изменения и новый interaction/mobile harness. Навык `code-review` потребовал
два независимых направления, Standards и Spec; исходные навыки не изменялись.

Standards проверил AGENTS.md и docs/development-workflow.md, научную
идентичность, ограничение ресурсов и failed-path cleanup. Spec сопоставил
поведение с №35 и явно отделил открытые gates от дефектов реализации.

Исправлены обязательные замечания:

- Для Mercator в cache identity было записано ортографическое определение;
  теперь используется EPSG:3857, отдельный PROJ-reference проверяет fallback.
- Выбор °C менял только название единиц; теперь общий форматтер переводит
  числовое point-значение и сохраняет его при переключении вида и новых кликах.
- Второй указатель мог перезаписать начало жеста; теперь отслеживаются pointerId
  и вся многопальцевая последовательность до полного отпускания.
- Mobile harness заявлял освобождение карты без проверки, не учитывал начальную
  карту при ранней ошибке и не регистрировал необработанные ошибки. Теперь
  release отменяет загрузки/point, удаляет active/initial map, проверяет отсутствие
  canvas и отключает управление; errors/rejections сохраняются и блокируют pass.
- POST телефона мог перезаписать поля host report; теперь копируются только
  разрешённые поля устройства, host inputs/commit/request log сохраняются.

Повторные focused review: обязательных замечаний по коду нет. Необязательная
рекомендация сохранять базовые mobile-результаты до interaction выполнена.
Осталась рекомендация сократить повтор выбора CRS в JS, сохранив независимость
Python-reference. Операционное замечание о времени жизни firewall helper
исправлено до приглашения phone3: до 25 минут на подготовку и оба ожидания
с обязательным досрочным удалением по stopfile после пробы.

Review не подтверждает непрерывное вращение, мобильные жесты, Safari/iOS или
performance budgets. Canvas-only снимки телефона не проверяют HTML-подписи
и контролы. Эти границы остаются явными в [проверке](validation.md).

Итоговый независимый audit Standards/Spec сверил выбранные desktop/phone
JSON и байтовые входы: обязательных замечаний нет. Подтверждены 113 frozen
файлов, совпадение проиндексированных SHA256 и девять retirement receipts.
Spec подтвердил отметки критериев 2/3/4/6/7 и открытые 1/5/8. Согласование
геометрии EPSG:3576 не приравнивается к полному визуальному pass телефона;
fallback проверен введением ошибки. Commit/push до полной приёмки не сделаны.
