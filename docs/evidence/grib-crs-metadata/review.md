# Review относительно исходной точки

Исходный commit: `27fef35a10f28d01f9e55b3b5b5dd2934ede9770`.
Review проведён до итогового ticket commit, включая новые файлы.

- Конфигурация читается до изменения очереди; один снимок передаётся всему
  заданию. Чтение опубликованных данных использует сохранённый снимок.
- Параметры стандартных кодов формы Земли имеют приоритет. Обязательные
  параметры проекции и неподдерживаемые варианты не подменяются умолчаниями.
- Порядок строк/столбцов нормализуется вместе со значениями и масками.
  Размеры и шаги проверяются до декодирования/публикации.
- Эффективный идентификатор сетки включает разрешённую CRS; повторная
  загрузка с другой конфигурацией не переиспользует геометрию старого поля.
- Числовой API выбирает исходную ячейку. Производный ГИС-COG имеет отдельную
  маркировку и проверяется относительно собственного полного растра.
- Старые версионные определения не редактируются. Сохранённые редакции
  доступны по прежним идентификаторам; новые сообщения не меняют их метаданные.
- Новые версии native/tiles проходят через те же ограничения gateway и
  авторизацию. Несоответствие версии выбранной публикации отклоняется.
- Пакет читает только непосредственные обычные файлы; сигнатура важнее
  расширения. Ошибка одного файла не скрывает результат остальных.
- Полный снимок CRS остаётся в отдельной коллекции и публикации. Обе копии
  исключены из списка коллекций, чтобы сохранить установленный лимит ответа.
