## Spec

Обнаружено и устранено одно P1: рендерер QGIS использует клон provider,
поэтому identify исходного provider мог оставаться на начальном времени URI.
PyQGIS 3.44 не предоставляет C++ mutator `setRequestedTemporalRange`.
Для identify теперь создаётся provider с точным временем текущей итерации.
Временной рендеринг по-прежнему проверяется динамически на основном слое.

Повторное ревью кода и разработочного отчёта QGIS подтвердило исправление:
20 наблюдений, два времени и две CRS; значения в центре различаются по времени
и совпадают с независимым числовым API. Новых замечаний нет.
Финальная приёмка и её исходные байты учитываются отдельно в validation.md.

После первой полной попытки отдельно проверены конфигурация T8 fault markers
и выбор сохранённой двухсрочной ревизии на фоне 24 сроков. Spec подтвердил,
