Первый QGIS capabilities-запрос получил 400: клиент опускает VERSION при
начальном согласовании. Gateway теперь выбирает 1.3.0 для GetCapabilities
без VERSION, продолжая отвергать неподдерживаемую явно указанную версию.
XML сериализуется с обычным default WMS namespace; отдельная причинность
префикса `ns0` не устанавливалась.

Первый desktop URI включал `type=wmst`, но не `timeDimensionExtent`:
provider был действителен, список времён оказался пустым. Helper теперь
переносит реальный список из scoped capabilities, а не придумывает диапазон.
Ссылки capabilities относительные; QGIS использует исходный абсолютный
scoped URL с штатными IgnoreGetMapUrl/IgnoreGetFeatureInfoUrl.

Ревью выявило независимую проблему времени identify; исправление описано в
[отчёте](review.md). Разработочная desktop-проверка затем прошла для 20 точек.
Диагностика не сохраняет URI слоя с ключом. Одноразовый ключ разработочного
стенда удалён вместе с организационным хранилищем при retirement.

Отдельная проверка mypy до финального Compose нашла nullable XML text;
обработка пустого текста исправлена, повторная проверка 51 файла прошла.
Эти `docker run --rm --network none` не создавали постоянных ресурсов проекта.
Вспомогательные справочные пробы PyQGIS уточнили недоступные Python-методы;
они не заменяют WMS/desktop gate и не изменяли пользовательский проект.

В первой полной попытке отсутствовал `T6_TEST_FAULTS=1`, который используют
существующие T8/T9 runners. Поэтому marker `.t6-generation` не мог включить
контролируемый отказ генерации; это ошибка конфигурации T11 runner, а не
установленный отказ gateway admission. Исправление включает флаг только
в изолированном тестовом API и выполняет T8 policies уже в Development.

Для повторной окончательной приёмки T11 выбрана сохранённая ревизия с двумя
сроками 01/03 на фоне более поздней публикации всех 24 сроков T5. Проверяется
весь временной домен именно выбранной ревизии, включая отсутствие 02 и более
поздних гранул; desktop проверяет ту же identity. Успешные фазы прежней попытки
не объединяются с новыми для заявления итогового результата.
