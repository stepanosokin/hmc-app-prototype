# T13 — рабочая GPU-карта: проверки разработки

Задача [№25](https://github.com/stepanosokin/hmc-app-prototype/issues/25),
исходный commit `ea89769c9f1de99bcec6e7118b66dc241d9f1770`, ветка `main`.
Это история попыток; окончательная приёмка фиксируется отдельно.
Демонстрационный T24 и исторические архивы T23/T23a не изменяются.

## Реализация

`viewer/` содержит TypeScript загрузку и выбор опубликованного прогноза,
MapLibre custom layer поверх принятого нативного GPU kernel и русский интерфейс
по T24. Нативные f32/mask/halo и однократная bilinear-интерполяция соответствуют
`hmc-native-display/1`; frozen v2, point/EDR/WMS и нативные данные не меняются.
Рабочая карта запускается сервисом `viewer` в существующем Compose.
Публичный bridge пересылает только разрешённые read-only пути к gateway;
он не пересылает credentials и сохраняет повторные query parameters.

Поле, локальная подложка/граница, подписи и точка используют одну геометрию.
Для вращаемой ортографии и EPSG:3576 контекст Natural Earth рисуется на Canvas2D
под числовым WebGL2-слоем; в LAEA используется тот же официальный proj4,
отсечение географических объектов выполняется до проекции. MapLibre сохраняет
карту и обработку масштабирования, GPU-значения не заменяются картинкой.

Выборки закреплены по расчёту/редакции/сроку. Пропуск срока удаляет слой/точку,
новые публикации принимаются явно. Запросы отменяются и проверяются после decode;
данные для нового срока не могут попасть в предыдущую GPU-выборку.
Единицы/палитра и проекция переиспользуют неизменённые числовые блоки.
Ресурсы ограничены 18 блоками, двумя запросами, 8 МиБ передачи и 128 МиБ
массивов/текстур/framebuffer, с canvas до 2048×2048 и DPR до 2.

## Попытки

Каждая Compose-попытка архивирована штатным retirement helper с проверкой
нулевых контейнеров, сетей и томов. Копии находятся в `attempts/dev1`…`dev9`.

| Попытка | Наблюдение и результат |
| --- | --- |
| dev1 | Реальная публикация прошла. Chrome не запустился: ошибочно выбран Program Files (x86); фактически установлен в Program Files. Исправлен путь и обработка ошибки запуска. |
| dev2 | Реальное поле и канонический клик показаны. Canvas глобуса перехватывал панели, а событие потери контекста удалённой карты меняло глобальное состояние. Снимок и отказ сохранены. |
| dev3 | Принудительная потеря контекста обнаружила ошибку диагностического readback: запрос возможностей потерянного WebGL возвращает нули. Диагностика теперь не читает потерянный контекст. |
| dev4–dev5 | До создания Docker-ресурсов сработала проверка Git-filter byte identity. Нормализованы собственные новые исходники и `.gitattributes`; исходные исторические байты не менялись. |
| dev6 | Полный текущий браузерный сценарий Chrome: 1440×900, 390×844, 640×360, три режима, девять канонических кликов; raw GRIB/PROJ сравнение прошло. Это Development: визуально обнаружены артефакты LAEA и оставшийся canvas прошлого вида. |
| dev7 | Проверены новый локальный LAEA-контекст, обычное восстановление GPU и понятный отказ при реальном `--disable-webgl`. Только desktop, Development. |
| dev8 | Browser прошёл; расширенный independent reference отклонил нечисловой projected pole в Mercator. Полюс не имеет конечной Mercator-позиции, поэтому этот случай не передаётся в PROJ как число. В остальных режимах он остаётся явным синтетическим тестом. |
| dev9 | Focused desktop: все три режима; GPU ≤0,002296114 K, маски 0 расхождений, DOM ≤0,0182 px, синтетическая геометрия ≤2,705 м. Raw-GRIB канонические клики прошли. Исправлено явное удаление Canvas2D при замене Map. Снимок LAEA просмотрен: ghost overlay исчез. |

`desktop1` прошёл Chrome/Edge на четырёх размерах экрана, включая минимальный
портрет 360×740 и landscape 640×360, с двумя шрифтами и обеими подложками.
GPU/PROJ/raw-GRIB и отказ WebGL прошли в обоих браузерах. Следующий T5 в том же
проекте закономерно отклонил начальный каталог: тест ожидает только первый срок,
а стенд карты уже содержит +1/+3 ч. Весь запуск сохранён как Development;
T5 перенесён в отдельный свежий проект без изменения его assertions.

## Ревью и дополнительные проверки

Два независимых review нашли и помогли устранить русские сообщения ошибок,
удаление точки на телефоне, stale context events, смену проекции при потере GPU,
быстрый fit без слоя и очистку Android после частичного отказа. Окончательные
вердикты Standards/Spec — открытых замечаний нет; они не заменяют приёмку.

Первый TDD-срез выбора расчёта сначала отклонён из-за отсутствующего модуля,
затем прошёл. Системная попытка Node test isolation получила `spawn EPERM`;
используется поддерживаемый `--test-isolation=none`. Ранние typecheck-ошибки
новых классов устранены. Четыре текущих Node-теста проверяют выбор первого
срока, пропуск часа, отмену устаревшего результата при игнорировании abort
транспортом, два конкурентных запроса, повреждённую маску и локальность URL.
Они не заменяют реальный Compose/GPU/Android.

`checks1`/`checks2` сохраняют stdout/stderr и native exit codes. Node/TypeScript
не создают тестовых серверов, профилей или контейнеров. Расширенный mypy в
`checks2` нашёл 13 ошибок в неизменённом `tools/diagnose-t23-service.py`;
отсутствие diff к исходному commit проверено до исправления. Временный
`--rm --network none` контейнер mypy проверяется отдельно после завершения.

## Физический Galaxy

Пользователь подтвердил Galaxy S25+ и физическую проверку. ADB Platform Tools
37.0.1 получены из официального Google archive; записаны URL, размер и SHA256.
Первые два Wi-Fi сопряжения дали protocol fault, а TCP к предоставленным портам
не прошёл. Коды сопряжения не архивируются. Пользователь выбрал USB.
Один task ADB-сервер 5041 и созданные task keys учитываются отдельно до финальной
очистки; они не являются результатом физической приёмки.

Safari/iOS остаётся ранее согласованной отсрочкой T23 и не объявляется
поддерживаемым. Полный нагрузочный отчёт принадлежит №31.

## Окончательные результаты

`android1` и `android2` публиковали реальное поле, но остановились на выборе
native select: pointerdown/up достигали нужного SUMMARY, совместимый DOM click
приходил позднее фиксированной паузы. Сохранены actual coordinates/events,
снимки и очистка. Runner теперь ожидает настоящий click перед следующим шагом.
`android3` прошёл три режима, canonical/raw-GRIB, drag/pinch и GPU маски.

После этого review подтвердил явный `releaseLayer` перед удалением старой Map,
удаление canvas и GPU ресурсов и сброс старой renderer error перед fit. Исправлена
русская aria-подпись canvas и компактная подпись LAEA. На окончательных общих
172 входах `desktop2` и `android4` прошли все browser/reference сценарии.
На Galaxy фактическая ОС Android 17, Chrome 155.0.8059.84, Adreno 830; это новая
проверка устройства, историческая версия Android из T23 не переносилась.

Свежий отдельный `t5-final1` прошёл полный service suite. `checks3` подтвердил
mypy всех 67 CI source files после минимального исправления типов диагностического
скрипта. Все 16 receipts и обе transient mypy очистки проверены; host task ADB,
его неизменённые ключи/пустой профиль и SDK удалены. Пользователь подтвердил
удаление новой записи телефона и выключение wireless debugging.

Итоговые числа, ограничения первичного frame measurement и соответствие каждому
критерию приведены в [приёмке](validation.md). Эти документационные дополнения
не меняют замороженные runtime inputs и не требуют нового запуска Compose.
