# Проверки исправления CRS исходных GRIB

Задача: [№48](https://github.com/stepanosokin/hmc-app-prototype/issues/48).
Начальный commit: `6fbd6a88cdb9916bdf6338af0097f66b487ee5bf`.

## Неудачные проверки совместимости

- pyproj из закреплённого `hmc-publication:t12` распознаёт исходную строку
  как повёрнутую производную географическую CRS, но не экспортирует её
  в WKT1_GDAL. Ошибка: `CRS cannot be converted to a WKT string of a
  'WKT1_GDAL' version`. Простая подстановка этой CRS в старую цепочку
  COG/GeoServer не выбрана.
- Первый запуск импортировал код из `/app`, а не mounted `/workspace` и
  завершился `ModuleNotFoundError: decoder.source_crs`. Исправлен workdir.
- В первичной проверке нового pipeline обнаружены округление радиуса при
  форматировании `:g` и выход углов в радианах. Исправлены полная точность
  радиуса и явное преобразование выходных углов в градусы.
- Публичный официальный пример GeoTools `General_Oblique` проверен в
  закреплённом GeoServer 2.27.0 / GeoTools 33.0. На реальных координатах
  исходного образца ошибка долготы составляет 180°. Полный вывод:
  [geotools-probe.log](geotools-probe.log); источник проверки:
  [GeoToolsProbe.java](../../../tools/source-crs/GeoToolsProbe.java).
  Например `(20,50)` даёт `(63.398853167127,60.759793334732)` вместо
  долготы `-116.601146832873`. Этот путь отвергнут; прежняя CRS не
  переопределяется. Возникший вопрос GIS-производной передан пользователю.
- Исправленный PROJ roundtrip:
  [proj-probe.log](proj-probe.log). Это вычислительная проверка, а не
  независимый географический эталон производителя.

Все перечисленные probes запускались через `docker run --rm`, без
Compose-проекта, томов и пользовательского браузера. Ресурсы действующего
стенда и исходные данные не изменялись. Последующие проверки и итоговая
очистка фиксируются отдельно.

## Промежуточные service/browser/GIS попытки

- `hmc-publication-crs48-dev1`: legacy-публикация прошла. PowerShell 5.1
  не разобрал новый русский скрипт без UTF-8 BOM; кодировка исправлена.
  Проект архивирован и полностью удалён.
- `hmc-publication-crs48-t5dev1`: T5 incremental/restart прошёл; full-suite
  обнаружил 404 вместо 400 для синтаксически некорректного времени.
  Валидация синтаксиса возвращена перед разрешением selection. Проект
  архивирован и полностью удалён.
- `hmc-publication-crs48-dev2`: 24 срока, 144 точки CRS84, сохранность
  legacy-редакции, Chrome/GPU (три проекции, максимум 0,007375 K, маски без
  расхождений) и QGIS 3.44.11 (два срока, EPSG:4326/3857, обычные размеры,
  DPI и Identify) прошли. Полный gate не выбран: входы менялись во время
  разработки, что обнаружил `inputs-end`. Проект архивирован и удалён.
- `hmc-publication-crs48-t6final`: несмотря на имя, Development-попытка.
  Семь recovery-сценариев прошли, затем legacy-публикация выявила старую
  копию decoder в образе при новом bind-mounted worker. Образ пересобран;
  смешанная попытка не является приёмкой. Проект архивирован и удалён.
- `hmc-publication-crs48-final`: preflight остановился на различии рабочих
  и будущих Git-байтов `.gitignore`. Переводы строк приведены к LF до
  повторной приёмки. Runtime-ресурсы не создавались; retirement подтвердил
  отсутствие ресурсов и сохранил журнал попытки.
- `hmc-publication-crs48-accept`: повторная полная загрузка и проверка всех
  18 блоков прошли, но правки проверки/браузера сделали входы различными;
  `inputs-end` отклонил попытку. Проект архивирован и удалён.
- Первый вызов T8 с именем вне разрешённого шаблона отклонён до создания
  ресурсов. Исправлено только имя проекта, процедура T8 не изменена.

Дополнительно исправлены обнаруженные при просмотре обходы: обычный
`storage build` теперь применяет соседний `proj.txt`, а экспериментальная
серверная отрисовка использует CRS выбранной публикации. Исторические
storage/worker пути сохраняются только с явными legacy-флагами.
В браузере при смене CRS обновляется контур покрытия без замены экземпляра
карты. Изменения просмотрены относительно начального commit.

У resource-free проверок сохраняются stdout/stderr и native exit codes.
Ошибки запуска (`tests` не является Python package, отсутствующий `npm.cmd`,
пропущенный mount `/input`) сохранены в журналах; исправлены вызовы,
а не ослаблены проверки. Итоговая приёмка и cleanup фиксируются в
отдельном итоговом отчёте.
