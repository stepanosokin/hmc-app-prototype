# Откат CRS и полное восстановление данных — 23.10.2026

Пользователь признал новую CRS ошибочной и потребовал отменить изменения,
заново обработав все текущие GRIB. Предыдущий план и все проверки повёрнутой
CRS отменены. Материалы в этой папке, кроме файлов `rollback*`, описывают
отклонённую попытку и не подтверждают правильность её геопривязки.

Рабочий код decoder/publication/viewer/tools/tests и исходная документация
восстановлены до `6fbd6a88cdb9916bdf6338af0097f66b487ee5bf`.
Новые модули, контракты, тесты и ADR новой CRS удалены из рабочего дерева.
Неотправленная реализация сохранена локально в
`data/archives/crs-rejected-20261023`; она не используется приложением.
Исходные GRIB и пользовательский `proj.txt` сохранены без изменения.
Файл `proj.txt` снова игнорируется Git и не применяется обработчиком.

В исходной папке находится один GRIB: `ICON_EU_T_G_2026101500.grib2`,
SHA256 `dddfd6c63ba73e5e7337c21e105f16417003429f8179a44ca58bb110cb43736a`.
Его 24 срока полностью пересозданы заданием
`ed6037f4-f53c-47d9-ad79-51c74ae492df` на исходном образе
`hmc-publication:t12`. Новое задание t6.1 не переиспользует прежние поля t5.1.
Итоговая редакция:
`ab10296dec6170d90af1ac44cd094d4db47fda92a9a6bf3f7f77b1091fd54c59`.
Восстановлена исходная CRS `+proj=longlat +R=6371229 +no_defs`.

Перед изменением каталога сохранён локальный pg_dump. Ошибочное задание
`5d994f3d-f3d5-414c-bc61-5313d0792379` остановлено, автоматический повтор
отключён; его 23 редакции удалены из активной таблицы редакций и помечены
истёкшими в retention. Их файлы и прежние корректные публикации сохранены.
23 промежуточные редакции нового полного восстановления исключены из discovery
через retention без удаления файлов; итоговая редакция содержит все 24 срока.
Это сохраняет каталог в пределах исходного ограничения браузера 1 MiB.

[Проверка данных](rollback-verification.json) подтверждает 24 новых редакции,
совпадение всех значений и масок Zarr с GRIB, штатные проверки Xarray/COG,
геопривязки и контрольных ячеек, 24 ответа point через gateway и отсутствие
ошибочных редакций в активной таблице. Сценарий: [rollback-verify.py](rollback-verify.py).

[Chrome](rollback-browser-3/browser.json) подтвердил загрузку новой итоговой
редакции и завершённого GPU-поля; [снимок](rollback-browser-3/initial-load-0.png)
просмотрен визуально. Это проверка начальной загрузки исходного интерфейса,
а не новая полная приёмка интерфейсных изменений: рабочий код интерфейса отменён.

Неудачные попытки сохранены: исправлен путь импорта проверочного сценария;
после ошибки API 503 перезапущен GeoServer для освобождения старых соединений;
до успешного запуска карты скрыты промежуточные редакции, превышавшие лимит
каталога. Первый запуск браузерного runner был запрещён sandbox до создания
браузера; повтор выполнен с разрешённым запуском процессов.

Временные проекты остановлены и архивированы; последние квитанции:
[frozen](rollback-frozen-retirement.json), [T8](rollback-t8-retirement.json).
Их незавершённые проверки отменены после смены задания, QGIS-проверка завершилась
ошибкой и не считается принятой. Ранее созданные квитанции в этой папке сохранены.
Итоговый инвентарь Docker содержит только пользовательский `hmc-app-live`
(пять работающих сервисов) и ранее остановленный сторонний `vgdb_tools`.
Одноразовые worker/check-контейнеры удалены, браузерный профиль и процессы
проверки удалены самим runner. Исторические свидетельства не изменялись.
