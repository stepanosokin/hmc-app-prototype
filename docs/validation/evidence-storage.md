# Внешнее хранение доказательств

Архив доказательств — полные результаты проверок: логи, отчёты, снимки входов,
скриншоты и receipts очистки. Хранить его в `HMC_EVIDENCE_ROOT`; по умолчанию
это соседний с репозиторием каталог `../hmc-app-evidence`.
На данном хосте: `D:\OSOKIN\PROG\HydroMetCenter\hmc-app-evidence`.

```powershell
$env:HMC_EVIDENCE_ROOT = 'D:\OSOKIN\PROG\HydroMetCenter\hmc-app-evidence'
```

Для каждого нового выполнения сохранять отдельный каталог, исходные отчёты
всех попыток, идентификаторы проверенных входов и подтверждение очистки.
Исторические результаты связывать с их прежними входами; будущее изменение
исходников не изменяет прошлый результат. Архив передавать/резервировать отдельно
от Git. GitHub clone не загружает внешний архив автоматически.

В `docs/validation/` оставлять краткий результат с границами проверки, путём
архива относительно `HMC_EVIDENCE_ROOT`, существенными ошибками, источниками
повторного использования и уже записанными хешами. Тяжёлые файлы и приватные
данные сюда не копировать. Секреты остаются в приватной конфигурации.

Fixture — необходимый для сборки или повторяемого теста эталон. Такие файлы
отслеживаются в `tests/fixtures/`, а проверочные программы — в `tools/`.
Принятый T4 выбор движка и T3 сравнение сохранены как fixtures: worker и
интегрированный runner продолжают применять их прежние проверки.
Обычные CI/local checks работают без исторического архива.

Историческую проверку запускать отдельно:

```powershell
powershell -NoProfile -File tools/check-archives.ps1
```

Отсутствующий архив явно обозначается как «не выполнено»; при присутствующем
архиве ошибка проверяющей программы остаётся ошибкой. Во время переноса
проверяли только явное сообщение при отсутствующем архиве. Проверки содержимого,
числа файлов, размеров и хешей пропущены по указанию пользователя именно для
этой операции. Будущие проверки сохраняют прежние правила.

Папка `docs/evidence/` исключена из отслеживания. Старые GitHub Issues и история
Git сохранены. Это изменение текущего дерева, а не уменьшение прежней истории.
Работающий `hmc-app-live`, его конфигурация и Docker-тома не меняются.
