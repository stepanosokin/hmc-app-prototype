# Прозрачные нули и независимая шкала

Задача [#68](https://github.com/stepanosokin/hmc-app-prototype/issues/68),
начальный commit `c84a9a7eb3b9272fa4d44ccf5ef4ba063e4e0268`.
Согласование 28.10.2026 уточнило исходный запрос NoData: нули сохраняются
численно и в статистике, но исключаются из цветовой шкалы и прозрачны.
Группы: давление, влажность, порывы, осадки, облачность, снег, видимость и
«Другое», включая неизвестные показатели. Температурные правила прежние;
нулевые скорость, направление и компоненты ветра видимы.

Отдельные метаданные оформления содержат диапазон видимых значений и
их количество. Полностью прозрачное поле сохраняет численные нули, не
показывает шкалу и отличается от NoData. Версия политики `field-validity/2`
инициирует пересчёт старых производных штатным операторским инструментом.
Worker и API используют текущий decoder через read-only mounts Compose.
Загрузка существующего файла через refresh по-прежнему пропускается.

## Приёмка

- 57 Node-проверок viewer и операторских инструментов; после уточнения
  mount API повторены 14 затронутых Node-проверок, все прошли.
- mypy: 108 файлов без ошибок. NoData: 15 сервисных тестов без пропусков;
  отдельный операторский preview/apply завершился успешно.
- WMS: ноль давления прозрачен при диапазоне 100000–102000 Па, сохраняется
  числом 0 в точке и GIS Identify; численный минимум остаётся 0.
- Chrome 155.0.8059.85 и Edge 156.0.4314.42: по 16 сценариев, размеры
  1440×900, 390×844, 360×740, 640×360. GPU readback подтверждает численный
  ноль и прозрачность; скриншоты малого portrait и landscape просмотрены.
  Мобильные размеры эмулированы; физические устройства не проверялись.
- Actual-GRIB T5: основной сценарий 187.960 с, сроки/исправления/читатели,
  перезапуск с сохранением значения 298.2274169921875 K. Общий набор:
  106 тестов, 33 ожидаемых пропуска; 68.092 с.
- 344 входа заморожены до приёмки, сверены после T5; все 344 файла во
  внешней копии независимо проверены по размеру и SHA256.
- Использован неизменённый образ зависимостей `hmc-publication:nodata65`,
  ID `sha256:1a18b692ee73813ef3a127e9381a2e631338ff73bb5a18a3c38841d199a71368`.
  T6/T7, отдельная desktop QGIS и исторические архивы не перепроверялись:
  механизмы восстановления, хранения, CRS и доступа не менялись.

## Диагностика и очистка

Сохранены шесть неуспешных попыток и отдельная диагностическая попытка.
Первый sandbox Node-запуск получил EPERM при spawn; разрешённый повтор прошёл.
Новая проверка смешанного поля ошибочно ожидала ноль в центральной GIS-точке,
затем использовала краевую точку с пустым Identify. Изолированное сравнение
COG и стилей подтвердило численный ноль во внутренней строке. Целевая регрессия
прошла за 5.141 с; экспериментальный стиль Identify удалён.
Дополнительно браузер выявил отсутствие decoder mount в собственном списке
томов API; исправлено и включено в конфигурационную регрессию.

Все восемь NoData/диагностических проектов и T5 удалены; receipts сохранены.
Независимая проверка семи ранних проектов показала 0 контейнеров/сетей/томов.
Браузеры подтвердили завершение процессов и удаление профилей. Resource-free
Node/docs-проверки не создавали тестовых сервисов. Live сохраняется по запросу.
