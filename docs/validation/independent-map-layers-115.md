# Независимый выбор фона и изолиний

[Задача №115](https://github.com/stepanosokin/hmc-app-prototype/issues/115),
25.11.2026. Уровень тестирования — средний. Проверки выполнены локально
на Windows с Node.js 26.10.0, Docker Desktop, Chrome и Edge.
Исходный коммит `8b97768bb19161a698622024b4b8bd2dafc58433`.

## Приёмка

- Chrome и Edge, по 25 зарегистрированных проверок в окнах 1440×900,
  360×740 и 640×360. Проверены две колонки,
  исходный выбор, совместное отображение температуры и давления, смена
  вертикального уровня, отдельная легенда и независимое отключение слоёв.
- Проверены пропуск изолиний и пропуск фона, сохранение текущего срока,
  шкала времени при двух пустых колонках, смена модели и расчёта. За
  горизонтом шкала изолиний скрывается, текст с шагом остаётся.
- Проверены карточка точки, график и привязанная ссылка API. При выключении
  фона они переключаются с температуры на давление и показывают данные
  опубликованного поля в единицах интерфейса.
- Дополнительный сценарий Chrome подтвердил отмену worker при отключении
  изолиний и отбрасывание запоздавшего результата при смене срока.
  `tools/check-local.ps1` завершился с кодом 0, включая Viewer, Windows
  и Runtime. Дополнительные проверки, требующие отдельных приватных данных
  или сервисов, пропускались по условиям штатного набора.

Ревью по проектным правилам и требованиям прошло на рабочем изменении.
Исправлены отмена устаревших загрузок, обработка ошибки изолиний и выбор
сроков с разным смещением. В браузерных отчётах сохранены замороженные входы,
каталог, наблюдения и снимки. Мобильные размеры проверены эмуляцией окна.
Прокси браузерного теста обслуживал прогнозные API и не обслуживал общий WMS.
