В Git сохраняются краткие результаты, ссылки на внешние архивы и записанные
идентификаторы. Полные логи, screenshots, повторные попытки и frozen snapshots
хранятся вне репозитория. [Реестр](archives.md) указывает их расположение;
[правила хранения](evidence-storage.md) описывают создание новых записей.

Сборка и обычные тесты используют отслеживаемые fixtures, исходники и lock-файлы.
Внешний архив нужен только для отдельной исторической проверки. Отсутствие
архива означает «историческая проверка не выполнена», а не успешную проверку.

При переносе 26.10.2026 число файлов, размеры и хеши не проверялись по указанию
пользователя. Существующие SHA256 переписаны из метаданных без пересчёта.
Это исключение относится только к переносу. [Результат T19](t19.md).
