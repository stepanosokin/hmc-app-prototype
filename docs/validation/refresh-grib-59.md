# refresh_grib — №59

26.10.2026. База: `46ae6d5d19535f270290471eeb954c2f29cfd473`.
Задача: [№59](https://github.com/stepanosokin/hmc-app-prototype/issues/59).

[Операторский скрипт](../../tools/refresh_grib.ps1) создаёт отдельный план,
показывает отсутствующие имена и ждёт «ДА». Затем вызывает существующие
sync apply, многополевой grib_batch и restart API/gateway. `-PlanOnly`
завершает работу без мутаций, `-Yes` явно пропускает подтверждение.
[ADMIN](../../ADMIN.md) содержит простой запуск и сохранённый ручной порядок.

Скрипт получает env/Compose-файлы и неизменяемый ID образа из существующего
API своего репозитория; полный Config.Env не записывается в журналы.
Стенд автоматически не запускается. Один бюджет 64 GiB передаётся обоим
этапам; окружение и каталог вызывающего окна восстанавливаются.
Принятые четыре publication fixtures копируются в новую папку отчёта
до операций. Пустой GRIB-набор пропускает загрузку; учитывается сигнатура,
а не расширение. Ошибки прекращают следующие этапы. Контейнер загрузки
удаляется только после проверки уникального имени и собственной owner-метки.

- 17 Windows-регрессий: подтверждение/отказ, PlanOnly, ошибки preview/apply/
  load/restart и отчёта, пустая/отсутствующая папка, extensionless GRIB,
  остановленный/чужой стенд, потерянный env, очистка своего контейнера и
  сохранение чужого, восстановление окружения. Копии fixtures сверяются SHA256.
- Полная actual-source проверка на отдельном проекте: отсутствующий исходник
  снят (его URL — 410), новый без расширения опубликован на 24 срока;
  исходный каталог записан. API/gateway перезапущены, каталог прочитан через
  gateway. Второй refresh с пустым GRIB-набором дал 0 публикаций без load.
- T5 actual-sample — 1 сценарий, persistent restart сохранил 28 партий/
  редакций; полный набор — 85 тестов, 29 ожидаемых пропусков. Полный mypy —
  102 файла. Полный Windows scope пройден после исправления; синтаксис всех
  36 PowerShell-файлов проверен. Регрессии включены в local/CI Windows gate.
- На `hmc-app-live` выполнен только окончательный PlanOnly: state=planned,
  0 снятий в плане, 41 GRIB к загрузке; apply/load/restart не запускались.
  Проверены ссылки и синтаксис восьми PowerShell-примеров ADMIN.
