# Названия и единый WMS — исследование

13.11.2026. [Вопрос исследования](https://github.com/stepanosokin/hmc-app-prototype/issues/101), [карта решений](https://github.com/stepanosokin/hmc-app-prototype/issues/100).
Исходный код: `1ff44c3f4f8f2090978e4b711ea2cf15d8362968`; QGIS final-3_44_11, GeoServer 2.27.0, WMS 1.3.0. Совпадение с live не устанавливалось.

## Результат

Оба изменения принципиально возможны: WMS допускает русские Layer/Title, отдельные технические Name и дерево слоёв одного сервиса. QGIS поддерживает обнаружение каталога через общий URL. Основание: [OGC 06-042](https://docs.ogc.org/is/06-042/06-042.pdf), §§7.2.4.6.2–4; [руководство QGIS 3.44](https://doc.qgis.org/3.44/en/docs/user_manual/working_with_ogc/ogc_client_support.html#loading-wms-wmts-layers).

Текущий [API](../../publication/api.py) обслуживает конкретные расчёт/редакцию/поле; объединения XML недостаточно. Рассмотрены общий API-фасад и отфильтрованный каталог GeoServer за gateway. Архитектура ещё не выбрана.

Причина наблюдения «без названия → единицы» **не подтверждена** без фактического XML/QGIS. [Публикация](../../publication/geoserver.py) задаёт SLD Title с единицами, API условно заменяет Layer/Title; это кандидаты для проверки. Диалог QGIS показывает дочерние стили, Browser использует заголовки слоёв — эти деревья нельзя отождествлять. [Исходник диалога](https://github.com/qgis/QGIS/blob/final-3_44_11/src/providers/wms/qgswmssourceselect.cpp#L344).

Ограничения: одно TIME для временных слоёв GetMap; у QGIS временной диапазон хранится в URI, автоматическое обновление открытого проекта не доказано. В collectDimensions обнаружен риск temporal metadata при выборе нескольких самостоятельных слоёв, в том числе перед добавлением отдельно; это вывод из кода, требующий будущего desktop-эксперимента, а не запрет общего WMS. [GeoServer TIME](https://docs-archive.geoserver.org/2.27.x/en/user/services/wms/time.html), [QGIS collectDimensions](https://github.com/qgis/QGIS/blob/final-3_44_11/src/providers/wms/qgswmssourceselect.cpp#L1069).

Сохраняются правила gateway, лимиты, научная идентичность, NoData/Identify и [снятие публикаций](../adr/0007-grib-publication-withdrawal.md). Скрытие слоя из Capabilities само по себе не запрещает прямые запросы. Динамический общий адрес требует отдельной семантики обновления и снятия.
