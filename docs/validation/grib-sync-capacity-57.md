хранилище — 31 150 297 349 байт, бюджет по умолчанию — 17 179 869 184 байта

передаваемое только одноразовому контейнеру синхронизации. Значение связано
с target и `storage_budget_bytes` плана. Другой бюджет требует нового просмотра;
изменение параметра при применении старого плана отклоняется. Проверки общего
объёма и свободного диска сохранены. Просмотр показывает размер/бюджет и
предупреждает, когда существующий объём уже превышает лимит подготовки замен.
