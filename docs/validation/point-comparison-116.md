# Два ряда прогноза в точке и шкала изолиний

[Задача №116](https://github.com/stepanosokin/hmc-app-prototype/issues/116),
25.11.2026. Согласован средний уровень тестирования. Среда: Windows,
Node.js 26.10.0, Docker Desktop и Chrome через интерфейс карты.
Исходный коммит `ddd79069d60d36f0e20a9ea07bfa6bf6abed4080`.

## Результаты

- Chrome выполнил 35 проверок в трёх размерах окна: 1440×900, 360×740 и
  640×360. Проверены порядок колонок, независимый выбор и отключение,
  пояснение у недоступного поля, отдельный штрих каждого показанного
  значения и пустое состояние шкалы. Проверены обе карточки точки, включая
  прокрутку графика в мобильном альбомном окне.
- Два значения сверены с отдельными ответами `/api/v1/point` для одной
  точки, редакции и срока. На графике проверены независимые масштабы, общая
  ось UTC, разрыв давления при работающем фоне, выбор срока и ветровые
  флажки. Проверены совпадение полей, два вертикальных уровня одного
  показателя и ссылка API с приоритетом фона.
- `tools/check-local.ps1` завершился с кодом 0 для Viewer, Windows и
  Runtime. Штатные сценарии, которым требуются отдельные приватные данные
  или сервисы, пропущены по условиям набора. В Chrome дополнительно прошли
  182 проверки ветровых, графических и палитровых фикстур.
- Регрессия T27 прошла на опубликованном 24-часовом ряде ICON-EU в четырёх
  размерах окна Chrome. Независимая сверка подтвердила 96 значений графика
  и 96 ответов EDR с нулевым расхождением в кельвинах. Пройдена проверка
  ошибок, повторных запросов, смены точки, истечения публикации и
  явного выбора срока. Неопубликованный срок доступен при наведении,
  кнопка выбора на таком сроке недоступна. Штатный набор T27 завершился
  успешно, хеши 463 входов совпали до и после прогона.

## Ревью

- По проектным правилам проверены обе копии карточки и резерв ресурсов.
  Общий бюджет карты учитывает по 16 МиБ на ряд до загрузки числовых
  ресурсов. Пока ряды загружаются, пустой график не пересобирается.
- По требованиям исправлены перекрытие графиков, выбор источника ветра
  при отсутствии фона, подписи уровней и точных сроков. На совпадающих
  участках видны обе линии благодаря штрихам тёмно-серого ряда.
