## Проверки и границы

- Пять служб работают; PostgreSQL и GeoServer — healthy. Интерфейс
  `http://127.0.0.1:8140/` и `http://127.0.0.1:8141/health` вернули HTTP 200.
- TypeScript собран; все 31 JavaScript-модуль, полученные по HTTP,
  совпали с компиляцией текущих исходников. Сохранён лимит карты 256 МиБ.
- Общий WMS через gateway и viewer вернул HTTP 200 за 14,7 и 20,5 секунды.
  В дереве «Гидрометцентр» доступны 30 конечных слоёв; каталог содержит
  русские названия и адреса операций с `snapshot`. Повторный запрос
  закреплённого каталога вернул HTTP 200 за 14,5 секунды.
- Первая попытка discovery через viewer завершилась `ResourceLimit`.
  Последующие три запроса успешны; точная причина первого отказа не
  установлена. Лимиты не менялись, гарантии быстродействия не заявляются.
- Первые вызовы build/start были прерваны обработкой диагностического
  stderr как ошибки PowerShell; повторены с проверкой native exit code.
  Первичная сверка ресурсов также исправлена: сравниваются множества
  подключений с нормализацией эквивалентных путей Docker Desktop.

Тома, подключения, сети и посторонние контейнеры сохранены: сверены все
11 существующих контейнеров; пересозданы только API, gateway и viewer.
Временных контейнеров не осталось, штатный отложенный сборщик завершился.
Изолированные стенды и браузерные профили не создавались; явно запрошенный
`hmc-app-live` оставлен работающим. Исходные GRIB не перезагружались.
Изменений исходников приложения относительно начального commit нет.

Это проверка применения сборки, а не повторная продуктовая приёмка.
Полный T11, desktop QGIS, браузерная матрица и историческая проверка
архивов не запускались. [Итоговая приёмка №105](wms-specification-105-completion.md)
сохраняет свои границы. №105 прочитана как CLOSED с 16/16 отмеченными
критериями; её состояние и чеклист этой операцией не изменяются.
