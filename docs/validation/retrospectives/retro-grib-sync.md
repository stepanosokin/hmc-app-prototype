# Ретроспектива снятия GRIB-публикаций (#52)

Источники — текущая сессия, commit `b59fb79cc4efb51dbce3e21943e29d081f5b6fc0`,
[результаты реализации](../grib-sync-52.md), исходный неудачный T13 и последующие
проверенные прогоны. Изменения этой ретроспективы относятся к среде агента.

1. **Необходимая fixture обнаружилась после долгого прогона.** В
   `process-results.jsonl` первого T13 отсутствовали overlap-seed/publish/restart;
   браузер остановился на скрытой кнопке `latestRun`. Причина — зависимость
   Updates от подготовки, которая запускалась только с Navigation. В #52
   условие уже исправлено. Новая [проверка fixture](../../../tools/check-viewer-fixtures.ps1)
   разбирает AST реального runner, проверяет четыре сочетания флагов и порядок
   seed/publish/restart до браузера. [Регрессии](../../../tools/check-viewer-fixtures-tests.ps1)
   отклоняют прежний дефект, AND вместо OR, безусловную/неполную подготовку,
   неправильный порядок и условия с побочными действиями. Runner и Docker
   при этом не исполняются. Проверка подключена к Windows/All и manual CI.

2. **Слишком широкий вывод отчёта.** Сериализация вложенного `updates` вместе
   с данными карты дала `original_token_count=4504939` до усечения инструментом.
   Для диагноза были нужны причина, текущая выборка, наличие новой публикации
   и очистка. [Краткая сводка](../../../tools/validation-summary.mjs) выбирает эти
   поля, ограничивает UTF-8-вывод 12 КиБ, отбрасывает вложенные raster/DOM/metadata
   и сокращает списки. JSONL показывает неудачные этапы, даже если последний
   cleanup прошёл; неизвестный exit code не считается успехом. Сырые отчёты
   сохраняются. Тесты включают большие вложения, длинный Unicode, типовые
   credentials в ошибках, BOM, повреждённый JSON и ограничение размера файла.
   Они подключены к Viewer/All и manual CI.

3. **Ревью потребовало нескольких проходов через связанные механизмы.**
   Отдельно корректные изменения нарушали общий порядок истории, бюджет
   хранения, durable references и происхождение при reuse. После добавления
   состояния снятия остался обработчик клика, который мог снова создать ряд.
   Это проверки смысла нескольких модулей, для них не вводится синтаксический
   запрет. [Существующие инструкции ревью](../../development/services.md#review-of-recovery-retention-and-budgets)
   теперь требуют проследить эти связи. [Подготовка приёмки](../../development/acceptance.md)
   направляет к ранней проверке fixture и ограниченной сводке. Существующее
   правило раннего визуального просмотра остаётся в
   [браузерных проверках](../../development/browser.md); указатель из ревью
   теперь срабатывает именно для недоступного состояния.

Уже существовали mypy, TypeScript, синтаксический parser PowerShell, Node-тесты
и общий launcher. Ошибки типов и отсутствие npm.cmd в первых попытках не
требуют новых линтеров. Полная установка Node/npm остаётся предусловием
локального Viewer/All; автономные Node-проверки используют установленный Node.
CI намеренно остаётся manual по принятому workflow; hooks и новые события
запуска не добавляются. AGENTS.md уже содержит нужные условные указатели;
глобальные инструкции и оригинальные сторонние skills не меняются.

Окончательные проверки 26.10.2026: 10 fixture-регрессий, 4 Node-теста сводки,
полный Windows scope и синтаксический разбор 33 PowerShell-файлов прошли.
Проверка реального прежнего runner из Git ожидаемо вернула exit 1 для
Navigation=False/Updates=True; текущий runner прошёл. На исходном отчёте
13 208 557 байт сводка заняла 2 336 байт, сохранив `latestRun`, выбранную
публикацию и успешную очистку. Хеш исходного отчёта не изменился; JSONL-сводка
сохранила прежнюю ошибку, несмотря на последний успешный cleanup.

Проверены 12 замороженных входов и их будущие Git-байты. Полные runtime-отчёты,
Windows transcript, snapshots и данные о неудачных попытках сохранены в
`HMC_EVIDENCE_ROOT/retro-grib-sync-53/final-20261026`. Все 32 скопированных файла
и полный снимок проверены по длине/SHA256. SHA256 `index.json`:
`4554B1D8FEE208283F42C396340E493C1725DE3BE8660205AFF71E044E2E7433`.
Запись с результатами завершена после runtime-проверок; её ссылки проверяются
отдельно как документационное завершение, с архивом
`HMC_EVIDENCE_ROOT/retro-grib-sync-53/completion-20261026`. Node/PowerShell unit-fixtures удалены

выделялись; продуктовые модули и browser/service runners не менялись.
