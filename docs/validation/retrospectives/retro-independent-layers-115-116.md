# Ретроспектива независимых слоёв и двух рядов прогноза

25.11.2026. Источники — переписка по #115 и #116, коммиты `ddd7906`
и `2fb0767`, записи приёмки [#115](../independent-map-layers-115.md) и
[#116](../point-comparison-116.md). Имена архивов указаны относительно
`HMC_EVIDENCE_ROOT`.

## Изменения по важности

1. **Состояние live в итоговом отчёте.** После закрытия обоих тикетов
   пользователь отдельно спросил, применены ли изменения к
   `hmc-app-live`. Перед обновлением #115 HTTP-проверка обнаружила пять
   устаревших модулей, перед обновлением #116 — четыре. В [порядке
   работы с тикетом](../../development/tracking.md) добавлена проверяемая
   версия работающего стенда для задач, в которых он фигурирует. Для
   сверки используется уже подключённый к локальным проверкам и manual CI
   `check-viewer-runtime.mjs`.
2. **Ресурсы отдельной копии Viewer.** Первый T27 по #116 потратил время
   на публикацию 24 сроков и остановился до первого сценария карты.
   В копии не было `land.js`, браузер получил HTTP 404. Полная копия
   ресурсов позволила пройти повтор, включая 96 сравнений графика и 96
   сравнений EDR. [Приёмка](../../development/acceptance.md) теперь
   направляет к существующему `viewer/prepare.mjs` до запуска Docker.
3. **Состав каталога перед браузером.** Первые попытки по #116 использовали
   10-метровый ветер для проверки недоступной опции. Для него шаг настроен.
   Дополнительное реальное поле оказалось температурой почвы с изолиниями.
   Сценарий прошёл с синтетическим ветром 100 м. Четвёртый срок дал
   непрерывный участок давления после пропуска и позволил проверить обе
   линии визуально. [Инструкция браузера](../../development/browser.md#other-browser-changes)
   теперь перечисляет процедуры и условия каталога. Если этот сценарий
   понадобится регулярно, проверку состава каталога стоит перенести
   в сам браузерный проверочный скрипт перед открытием Chrome.
4. **Диагностика длинных прогонов.** Один Chrome-прогон #116 прошёл 35
   утверждений и завершился ошибкой CDP `Invalid InterceptionId`. Повтор
   на тех же данных прошёл целиком. Первый отказ T27 вывел 6209 строк
   журнала. Отдельные файлы позволили найти причину отказа и сохранить
   полный вывод. Для этих случаев подходят уже описанные
   [повтор с замороженными входами](../../development/browser.md#other-browser-changes)
   и [ограниченный вывод процессов](../../development/acceptance.md).
