# Ретроспектива изолиний hmc-app-live — №75

Задача среды агента — [№76](https://github.com/stepanosokin/hmc-app-prototype/issues/76).
Источники: текущая сессия, [первичный результат №75](../contour-live-75.md),
commit `cfd7e09a6cc684af135891f5cc319e9f7b569b02` и выбранные первичные отчёты
`HMC_EVIDENCE_ROOT/contour-live/`: `repro-01`, `applied-01`,
`green-04/06/07/08`, `publication-01`. Исходная №75 остаётся закрытой, 5/5.

1. **Изолированная приёмка не обнаружила старую сборку существующего live.**
   Обновлённый HTML читал старый JavaScript из отдельного bind mount;
   в main отсутствовал runtime, модули изолиний возвращали 404.
   [Read-only проверка](../../../tools/check-viewer-runtime.mjs) компилирует
   текущие исходники TypeScript в память и сравнивает каждый модуль с байтами
   HTTP-ответа. Она обнаруживает старый main, отсутствующий worker, HTML fallback,
   ошибку HTTP/сети и не изменяет `data/viewer/build`. Тесты включены в существующие
   Viewer/All и manual CI. [Браузерная инструкция](../../development/browser.md)
   ведёт к этой проверке до выделения браузера, а [ADMIN.md](../../../ADMIN.md#обновление-кода-просмотрщика)
   объясняет диагностику и применение сборки. Автоматическое обновление live
   не добавлено: ранее auto-review отклонил эту операцию, затем владелец явно
   разрешил её. Read-only диагностика позволяет подготовить проверяемый результат.

2. **Параллельные браузеры упёрлись в бюджет общего стенда.**
   `green-04/06` не загрузили основное поле из-за HTTP 429, хотя runtime уже был
   доступен. Их последовательные повторы `green-07/08` прошли. Правило
   последовательного запуска уже появилось в ADMIN по итогам №75; теперь
   условный путь диагностики в браузерной инструкции ведёт к нему до матрицы.
   Лимиты сервиса и механизм браузерного runner не меняются.

3. **Слишком широкий вывод повторил уже известную проблему.**
   В сессии сырые отчёты и пакетное чтение больших документов усекались
   инструментом. Краткая сводка уже существовала и была подключена к local/CI,
   но отбрасывала объект `state` прямой проверки и не показывала HTTP-ошибки.
   [Сводка](../../../tools/validation-summary.mjs) теперь сохраняет только
   ready/canvas/состояние изолиний, размер окна, число нарисованных пикселей
   и счётчики HTTP 4xx/5xx. URL, тела ответов и вложенные данные не выводятся.
   Тесты сохраняют предел 12 КиБ и редактирование типовых credentials.

TypeScript, Node-тесты, проверка ссылок и PowerShell уже были подключены к
локальным командам и ручному CI. Новый тестовый framework, hooks и новые события
CI не нужны. AGENTS.md содержит достаточный условный указатель на таблицу проверок;
он и оригинальные сторонние skills остаются прежними. Sandbox EPERM дочернего git
в предкоммитной проверке №75 не был дефектом проекта: повтор с нужными правами
прошёл, ресурсы не создавались. Новое разрешение на чтение секретов не требуется.

Изменения этой ретроспективы относятся к диагностическим инструментам и навигации.
Приложение, научные допуски, исходные данные и пользовательский hmc-app-live
сохраняются. Физический Android остаётся отложенным по решению владельца;
повторная научная и полная историческая приёмка не входят в эту работу.

Проверки 30.10.2026: полный локальный Viewer gate — TypeScript и 91 тест,
из них 5 проверок read-only сборки и 6 сводки; PowerShell — 38 файлов;
ссылки — 5 документов. Проверены индексы и все файлы восьми выбранных первичных
архивов №75. Контролируемый HTTP-адаптер над реальными 17 старыми модулями
обнаружил 8 несовпадений, включая старый main и отсутствующий worker;
текущий live прошёл сравнение 22 модулей. Это read-only проверка сборки,
а не повтор браузерной/научной матрицы. Хеши сборки, каталог публикаций и
ID/образы пяти live-контейнеров сохранены. Браузеры и тестовые сервисы
не создавались, временные каталоги тестов удалены самими тестами.
