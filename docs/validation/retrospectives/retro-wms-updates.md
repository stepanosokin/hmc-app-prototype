# Ретроспектива обновления прогнозов WMS — №108

Основание — текущая сессия, [результат №108](../wms-108.md),
[индекс первичных материалов](../wms-108.archives.json) и коммит
[42558f5](https://github.com/stepanosokin/hmc-app-prototype/commit/42558f5eaf1369c12d619a2586119847f3141cfa).
Пути первичных журналов ниже заданы относительно `HMC_EVIDENCE_ROOT/wms108/`.

1. **Высокий приоритет — параллельная мутация ещё готовящегося стенда.**
   В `dev2-fixture-scope-failed/updates-red.stderr.log` новый сценарий получил
   404 вместо каталога; в `access-regression.stderr.log` базовый WMS получил
   410 вместо 200. Во время Prepare был запущен отдельный withdrawal-сценарий,
   а происхождение synthetic GRIB указывало на каталог реального образца.
   Ошибки fixture исправлены в №108. [Acceptance](../../development/acceptance.md)
   теперь требует дождаться успешного выхода Prepare, сериализовать мутации
   одного проекта и передавать в preview/apply фактическую область источников.
   Связь fixture с реальным источником — смысловая проверка; текстовый линтер
   не докажет её корректность. Продуктовый дефект наследования старой редакции
   отдельно воспроизведён в `dev3/updates-red.stderr.log` и исправлен в №108.

2. **Высокий приоритет — второй ручной список frozen inputs.**
   `static-final/freeze-start.json` обнаружил шесть пропусков: Dockerfile,
   Dockerfile.adapters, compose.adapters.yaml, compose.tls.yaml,
   compose.workloads.yaml и compose.yaml. В №108 они досохранены с доказанным
   совпадением первоначальных хешей; прежний архив не заменён.
   Добавлен [copy-validation-inputs.mjs](../../../tools/copy-validation-inputs.mjs):
   он копирует весь массив `inputs` готового service manifest, проверяет
   размеры/SHA256 и отклоняет дубликаты, private paths, symlinks/junctions,
   перезапись и изменившийся manifest. Это детерминированная проверка,
   поэтому вместо нового правила reviewer добавлен исполнимый инструмент.
   Его [регрессии](../../../tools/test-copy-validation-inputs.mjs) подключены
   к Windows/All и существующему Windows job manual CI.

3. **Средний приоритет — поздно найдено согласованное уточнение QGIS.**
   Первый desktop-драйвер использовал незакреплённый discovery URL, поэтому
   повторное открытие проекта получило новый прогноз. В текущей беседе это
   видно по Identify 290 K вместо 280 K. Уже существующий
   [результат №106](../wms-106.md#согласованный-контракт) и
   [инструкция QGIS](../../qgis.md#обычное-подключение-публичного-слоя) объясняют
   утверждённое решение: общая ссылка закрепляет каталог; для нового прогноза
   пользователь заменяет URL подключения новой ссылкой. Ранний условный
   указатель добавлен в [QGIS guidance](../../development/qgis.md).
   Новый контракт и отдельный несовместимый способ подключения не вводятся.

4. **Средний приоритет — лишний вывод и повторное изобретение проверок.**
   В начале сессии пакет с широким списком GitHub metadata превысил 23 тысячи
   токенов; большие пакетные чтения неоднократно обрезались. Tracking уже
   требует сначала отбирать имена, затем metadata выбранной операции.
   Acceptance уже указывает на bounded summaries и full-source mypy;
   эти правила сохраняются без дублирования в AGENTS.md. Ошибки FORMAT,
   ожидаемого статуса, сырого JSON и PYTHONPATH относятся к focused-драйверу;
   исправления и повторяемые probes уже вошли в №108.

Проверены существующие package/check scripts и `.github/workflows/checks.yml`:
типизация, viewer, документация и ресурсные границы уже имеют local/manual CI.
Общего pre-commit hook нет; автоматические CI-триггеры остаются предметом
отдельного решения, новая проверка добавлена в существующие entrypoints.
AGENTS.md, глобальные настройки, сторонние skills, код приложения и
результаты/закрытое состояние №108 этой ретроспективой не изменяются.

Пользователь согласовал **минимальный** уровень, Windows PowerShell и локальные
проверки документации/синтаксиса/затронутых инструментов без продуктовых
Docker/QGIS-стендов. Пройдены 12/12 Node-проверок (8 нового copier и 4 существующего
архиватора), ссылки пяти документов, Node syntax и PowerShell syntax изменённого
`check-local.ps1`. Проводка local/manual CI просмотрена; сам GitHub Actions
не запускался. Дополнительно API copier сверил все 226 входов сохранённого
service manifest №108 с архивными байтами, а CLI скопировал пять текущих входов
инструментов. Это проверка копирования, не повтор T5/T11 или исторической
научной приёмки. Проверенные исходники инструментов сохранены с manifest.

Первый запуск `node --test` остановился на sandbox `spawn EPERM` до тестов;
последующие использовали `--test-isolation=none`, как существующий viewer suite.
Обе попытки и итоговые результаты сохранены. Временные каталоги unit-тестов
удалены с проверкой; replay-копии оставлены в отчёте как доказательства.
Сервисные, браузерные и QGIS-ресурсы не создавались. Изменения просмотрены
относительно `42558f5`; новых правил в всегда загружаемые AGENTS.md не добавлено.
