# Ретроспектива полного каталога WMS — №107

Основание — текущая сессия, [результат №107](../wms-107.md),
[индекс первичных журналов с SHA256](../wms-107.archives.json), коммит
[ee330e5](https://github.com/stepanosokin/hmc-app-prototype/commit/ee330e525064f1ed4923f2554f8bf438506766dd)
и последующее явно запрошенное обновление `hmc-app-live`.
Пути ниже заданы относительно `HMC_EVIDENCE_ROOT/wms107/`.

1. **Высокий приоритет — полную приёмку запускали до готовности fixtures.**
   `dev6-fixture-date-failed/catalogue-http.stderr.log` показывает несогласованные
   границы статистического интервала. В `dev7-cli-error-observer` после 152 с
   тест искал сообщение worker в stderr, хотя команда возвращала JSON в stdout.
   `service-final2-restart-fixture-mismatch/t5-restart.stderr.log` содержит
   `revision discovery changed after restart`: verifier исходного одного поля
   получил расширенный многополевой каталог. Это ошибки подготовки проверки;
   средний уровень тестирования сам по себе их не требует. Исправления вошли
   в №107. [Подготовка приёмки](../../development/acceptance.md) теперь требует
   сверить состояния соседних сценариев и пройти новую failure/recovery ветку
   в Development до полного сервиса/QGIS. Это проверка смысла fixtures, а не
   синтаксический шаблон для линтера.

2. **Высокий приоритет — готовая регрессия сработала слишком поздно.**
   `browser-final2-matrices-pass-suite-failed/full-suite.stderr.log`: браузеры
   прошли, затем полный suite завершился с тремя ошибками `CompactCatalogue`
   за 63,254 с. Новое получение WMS-имени заставляло старый compact discovery
   читать манифесты вместо сохранённой идентичности. Приложение исправлено
   в №107. Существующий [test_catalogue.py](../../../tests/test_catalogue.py)
   подключён к [Runtime/All](../../../tools/check-local.ps1) и
   [manual CI](../../../.github/workflows/checks.yml); новые тесты не добавлены.
   Проверены существующие package scripts, Compose typecheck и CI: проверки
   типов/просмотрщика уже подключены. Pre-commit hook отсутствует, CI остаётся
   `workflow_dispatch`; автоматические триггеры в этой ретроспективе не меняются.

3. **Средний приоритет — браузерный драйвер и повторные полные прогоны.**
   Выбор старого расчёта закрывал drawer; его приходилось открыть заново.
   Целевая матрица получила 429 при параллельной загрузке ветра; журнал шлюза
   подтвердил `admission=concurrency`. [Browser guidance](../../development/browser.md)
   направляет к уже существующему focused-сценарию, реальному ready-состоянию,
   точному выбору поля и разбору причины admission. Лимиты приложения сохранены.
   В `completion-precommit/runner-only-change.json` зафиксировано 413 неизменных
   входов и единственная правка порядка `run-qgis.ps1`: повторяется затронутый
   сервисный gate, успешные браузерные результаты сохраняют свои исходные
   снимки. В acceptance добавлен условный порядок такого решения перед новым
   стеком. Общая проверка freeze уже существует и не дублируется в AGENTS.md.

4. **Средний приоритет — состояние desktop-инструмента и понятный статус.**
   Отдельные вызовы QGIS MCP не сохраняют Python namespace. В
   [QGIS guidance](../../development/qgis.md) записан способ удержать только
   временный probe между UI-шагами и удалить его при cleanup. Пользователь
   отдельно спрашивал, что означает T11 и завершена ли работа: статусы должны
   называть назначение проверки и оставшиеся действия до commit/push/закрытия.
   Реализация и rollout уже различены в acceptance; новая обязательная доставка
   на live не вводится. В этой сессии rollout выполнен отдельным запросом:
   `live-update-ee330e5/deployment.json`, `verification.json`, `live-smoke.json`
   подтверждают 31 JS-модуль, 2 модели/30 WMS-слоёв и сохранённые 40 редакций/тома.

Изменены профильные документы и проводка существующей проверки. Глобальные
AGENTS.md, сторонние skills, CODING_STANDARDS и код приложения не менялись:
механический пропуск исправлен подключением детерминированного теста, остальные
выводы касаются состава сценариев и зависимостей результатов.

Пользователь выбрал **без тестов** и согласовал Windows/PowerShell. Тесты,
синтаксический checker и проверка ссылок для этой ретроспективы не запускались;
новая проводка local/CI просмотрена статически, её выполнение не подтверждено.
Docker/QGIS/browser ресурсы не создавались, live-команды не выполнялись.
