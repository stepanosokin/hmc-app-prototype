# Ретроспектива TLS — №33

03.11.2026. Разобрана текущая сессия, завершившая реализацию №33 коммитом
`c70f608de5dacd5a137627f548bb9ac8448f8a7a`.
Результаты и ссылки на первичные архивы — в [приёмке T21](../t21.md).

1. **Высокий приоритет — скрытый вывод не означает отсутствие журнала.**
   `capture=false` исключал токен из отчёта Node, но одноразовый контейнер
   наследовал Docker `json-file`. В №33 чтение токена переведено на
   `--log-driver none`; TLS-сценарий повторён на `final3`.
   В [service checks](../../development/services.md) добавлена проверка всего
   пути секрета: вывод процесса, Docker и отчёт проверяются отдельно.
   Это решение по потоку данных, а не синтаксический запрет `print`:
   отдельный линтер по строкам кода здесь дал бы ложные срабатывания.

2. **Средний приоритет — новый файл мог не попасть в снимок входов.**
   Старый T8 collector выбирает пути по расширениям; новые `.mjs` и `.conf`
   сначала остались вне него. №33 добавил явный TLS inventory и сверку байтов.
   В [acceptance](../../development/acceptance.md) теперь указано сравнить
   фактический выбор collector с зависимостями изменённых файлов до freeze.
   Проверяемый результат — все входы затронутой проверки есть в обоих manifests.

3. **Средний приоритет — обратная связь по proxy приходила после подготовки GRIB.**
   Первичные `t21/dev1/reports/tls-007.log` и `t21/dev2/reports/tls-007.log`
   фиксируют лишний аргумент `nginx` и запись в read-only каталог.
   Затем `t21/final1/reports/tls-gate.json` выявил старый сертификат после reload.
   Короткий `t21/probe2/reports/probe.json` воспроизвёл отказ; изменение одной
   настройки в `probe3` дало 20 успешных циклов замены/возврата.
   В service checks добавлен порядок: сначала proxy-only цикл с реальными
   ограничениями контейнера и наблюдаемым сертификатом, затем полный T8/TLS.

Существующий TLS-сценарий уже проверяет одинаковые timestamps и фактические
серийные номера. CLI-тесты и документационные проверки подключены к локальным
проверкам и manual CI. Дополнительный набор тестов и отдельный framework
ретроспективе не потребовались. Изменения ограничены инструкциями, доступными
через существующие ссылки workflow; новый текст в AGENTS.md не добавлялся.

Проверены ссылки пяти изменённых документов и staged diff. Для шести выбранных
первичных файлов сверены размеры и SHA256 с индексами; SHA256 индекса `final3`
совпал с записью T21. Это выборочная проверка источников ретроспективы,
а не повторная историческая приёмка №33. Тестовые ресурсы не создавались.
