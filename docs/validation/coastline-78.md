## Результат и минимальная приёмка

- Natural Earth v5.1.2 `ne_110m_coastline`, 1:110m: постоянная береговая линия
  материков и островов, без заливки, границ государств и озёр. Линейный источник
  не создаёт замыкающих сегментов обрезанных полигонов. Происхождение и хеш
  источника: [паспорт данных](../../viewer/coastline.README.md).
- Тонкая нейтральная линия с контрастной обводкой находится выше растра,
  ниже ветра, изолиний, подписей и маркера. Учтены удаление/перемонтирование,
  общий бюджет памяти, смена подложки и повтор миров в Меркаторе.
- `npm --prefix viewer run check` и `node viewer/build.mjs` завершены успешно.
  Сборка применила изменение к работающему `hmc-app-live` без пересборки API,
  перезапуска служб или изменения публикаций. Runtime readback: все **27**
  модулей совпали по байтам с компиляцией текущих исходников, HTTP/MIME корректны.
- Единственный целевой сценарий Chrome 155.0.8059.85, Windows, 1440×900:
  **8/8** случаев — четыре проекции и две подложки, реальное поле `t`,
  масштабирование, поворот глобуса, сохранение выборки, ненулевая незалитая
  линия и порядок слоёв. Просмотрены все восемь окончательных снимков:
  контуры читаемы поверх растра, ложных линий по горизонту/45° нет.
  Ветер успел загрузиться в четырёх случаях и рисуется выше берега.
  Изолинии в прогоне выключены: их порядок подтверждён CSS и ревью,
  отдельная проверка построения изолиний не выполнялась.
- Standards-ревью: замечание о допуске памяти canvas исправлено до приёмки;
  повторное ревью — 0 открытых замечаний. Spec-ревью — 0 замечаний.
  `git diff --check` и проверка локальных ссылок изменённых документов успешны.

Полная тестовая и браузерная/физическая матрицы явно исключены пользователем;
они не считаются выполненными. Научные/API/QGIS-контракты не менялись.
Историческая проверка архивов отдельно не запускалась.
