## Согласованный контракт

Обычный диалог QGIS использует advertised адреса текущего слоя, но сохраняет
исходный URL подключения. При повторном открытии проекта общий изменяемый URL
снова получает каталог и переключает Map/Identify/Legend на новые адреса.
Это воспроизведено read-only loopback-прокси перед реальным публичным GIS-шлюзом;
изменение адресов в опыте не было публикацией нового реального прогноза.

Пользователь согласовал замену: обе точки приложения получают последние
публикации и копируют один общий URL `/gis/v1/wms?snapshot=…` всего закреплённого
каталога. Старый расчёт в приложении не меняет выбор последних публикаций этой
ссылки. Для новых данных нужно получить новую ссылку, заменить URL подключения
QGIS и заново добавить слой. Уточнение внесено в №105/106, без закрытия родителя.

Фасад остаётся за GIS-шлюзом и существующим GeoServer. Ссылки не содержат ключей;
авторизация, бюджеты и eligibility проверяются заново. Идентичность модели
сохраняется в retention registry, включая tombstones после GC. Изменение не
продлевает хранение и не меняет научные значения/NoData. Объём приёмки —
минимальный опубликованный набор температуры; полный каталог относится к №107.

## Review

### Standards

Независимый review относительно исходного коммита выявил guard старого формата
настроек QGIS, неполное восстановление проекта и английский 503. Исправлены
modern connection guard, восстановление CRS/dirty/filename/extent и локализация.
После повторного review замечаний не осталось.
Полный suite выявил передачу клиентского Host в public bridge просмотрщика.
Передача удалена; адреса общего WMS переписываются только в XML-ответе.
Отдельный тест проверяет отсутствие headers/cookies upstream, четыре операции,
параметры LegendURL и URL снимка без REQUEST.

### Spec

Исправлены необработанные английские сетевые ошибки UI и возможность возврата
старого расчёта при разных run-prefix одной модели. Дополнительно проверены
миграция уже физически собранной истории и равные publication timestamps
original/replacement. Модель выбирается до eligibility; допустимая замена
предпочитается только внутри одинаковых reference time и publication timestamp.
Повторный review не выявил оставшихся контрактных ошибок.
Полная мобильная матрица выявила перекрытия toast/закрытия и wind dock/навигации;
компоновка исправлена и проверена review. Фиксированная точка drag в runner
попадала в SELECT уровня ветра: двухсекундный DOM-repro подтвердил перехват.
Runner использует существующий projection-aware picker свободной точки canvas;
20 trusted movements, 60 px, проверка центра до pointerup и ≥5 кадров сохранены.

## Проверки и материалы

Реализация, review и итоговая приёмка завершены. Эта запись подготовлена до
единственного ticket-коммита: на этой фазе push и закрытие ещё ожидаются;
итоговые SHA/состояние фиксируются в комментарии задачи после push.
Полные отчёты, журналы, проекты QGIS и снимки исходников хранятся отдельно.
Историческая проверка прежних архивов не выполнялась.

Development: HTTP значения/NoData в двух CRS, карта/легенда/Identify, exact TIME,
отзыв ключа, очереди/ожидание, публикация/expiry/снятие, collected-tombstone upgrade;
обычный QGIS add/publication/reopen; выборочный Chrome и T7 Development пройдены.
Full-source mypy: 127 файлов; viewer suite: 82/82; TypeScript и PowerShell syntax
пройдены. Неудачный запуск `npm.cmd` не запустил тесты; suite выполнен через Node.

Итоговый T11 final2 прошёл actual-source T5, scoped/common HTTP, T8 regression,
очереди/ожидание/отзыв T9, restart и lifecycle с физическим GC и миграцией старой
схемы. Desktop: 48/48 холодных случаев QGIS, обычный диалог с общим URL,
новая публикация и повторное открытие сохранённого проекта; отдельно проверены
URL из браузерного буфера и виртуальный 3201×1801 (не физический 4K).
Карта/Identify/легенда закреплены, новая ссылка выбирает новую редакцию.
Полный Python suite: 137 тестов, OK, 47 ожидаемых пропусков.

Chrome final5 и Edge final6 прошли полную матрицу 1440×900, 390×844,
360×740, 640×360, обе точки копирования, старый расчёт, навигацию и независимое
численное сравнение. Edge также прошёл unavailable-GPU и полный Python suite.

исчерпала общий public budget: HTTP 429 в native block совпали по времени с

свежем стенде без второго клиента. Chrome не повторялся: его полный результат
успешен, все 444 входа неизменны и совпадают с Edge final6.
Замороженные копии проверены по размеру/SHA256; сравнение с основной рабочей
копией выявило только LF/CRLF неизменённых checkout-файлов. Все 31 актуальных
JS-модуля скомпилированы в памяти и совпали с проверенной браузерной сборкой.
