## Результат

Русский интерфейс сравнивает исходное поле с шагами ×2/×4/×8 на одной карте,
сохраняя выборку, камеру и исходный график. Изолинии используют выбранную сетку;
экранное скругление составляет 0,6/2/4/8 CSS px. Это радиусы алгоритма,
а не принятый допуск смещения изолиний. Усреднение взвешено по перекрытию ячеек
в исходных координатах; пропуски сохраняются консервативно. Исходный API не меняется.

Chrome 156.0.8078.74 и Edge 156.0.4314.58, Windows, headless, 1280×800 DPR=1:
48 сценариев = два браузера × температура/давление/осадки × обзор/приближение × четыре варианта.
Проверены одинаковые selection/camera, фактическая проекция LAEA — РФ, изменение масштаба,
сетка worker, переключения и защита от гонки выбора уровня. Ошибок браузера нет.
Диапазоны по этим одиночным измерениям:

| Шаг | Переданные данные поля, МБ | Загрузка, мс | Построение изолиний, мс | Управляемая память, МиБ |
| --- | ---: | ---: | ---: | ---: |
| 1 | 10,66 | 165–313 | 385–2225 | 86,5–86,7 |
| 2 | 2,67 | 58–92 | 139–695 | 66,7–66,8 |
| 4 | 0,67–0,68 | 24–52 | 42–387 | 61,7–61,8 |
| 8 | 0,34 | 17–49 | 21–176 | 60,9 |

Снимки подготовлены заранее; подготовка записана отдельно в `*-preparation.json`.
Это не измерение холодного production API, WAN, полной памяти процесса или p95/SLA.
`complete_ms` включает стабилизацию runner; upload измеряет CPU submit, не завершение GPU.
Ветер выключен для сравнения. Другие проекции, физический Android и большие окна
в итоговую матрицу этого эксперимента не входят.

Точка Москвы (37,6173; 55,7558): по десять значений для каждого из трёх полей
совпали между браузерами и не изменились при переключениях. Выбранный срок независимо
сверен с исходным `/api/v1/point`; используется ближайшая исходная ячейка.
График продолжает запрашивать исходный API по срокам: его ускорение и задержка
этим экспериментом не измерялись. Требование точного значения не заставляет карту
загружать исходную сетку для отображения.

- Независимый `verify.mjs` на трёх итоговых snapshots: 20 919 производных отсчётов,
  SHA256, footprint/CRS/identity, средние, маски и все halo прошли.
  Проверяется соответствие исходному native API; независимое декодирование GRIB не повторялось.
- 72 замороженных исходника неизменны; 47 фактически отданных runtime-ресурсов
  сохранены и сверены по SHA256. Полные списки входят в архивы inputs/runtime.
- Standards/spec review против исходного commit: исправлены гонка селектора,
  проверки камеры/проекции, проверка места изменения worker и фиксация runtime.
  Повторный review не обнаружил блокеров; затем выполнена итоговая матрица.
- Просмотрены итоговые снимки температуры (исходный/×8, обзор) и осадков (×4, приближение).
  Галерея `final-chrome/comparison.html` содержит все четыре варианта на каждом поле/масштабе.
  Визуальный выбор пользователя ещё не сделан.
- Проверка ссылок изменённых документов и `git diff --check` выполнены отдельно;
  ресурсных стендов они не создают. Историческая проверка всех прежних архивов не выполнялась.
