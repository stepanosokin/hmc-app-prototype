[спецификация №105](https://github.com/stepanosokin/hmc-app-prototype/issues/105).

## Изменение

Worker больше не выбирает предыдущую доступную редакцию как основу загрузки,
если последняя снята, истекла или уже физически собрана. Сначала определяется
последняя публикация по сохранённому retention registry, затем проверяется
доступность. При недоступности следующая поставка начинается без старых полей.
Допустимая замена частично снятой редакции сохраняет её место в порядке
публикации; научные значения, права, лимиты и сроки хранения не меняются.

HTTP-регрессия воспроизвела прежний дефект: после снятия редакции с давлением
новая поставка давления возвращала также температуру из более старой редакции.
После исправления в новой редакции остаётся только давление.

Применяется согласованное в №105/106 уточнение: приложение выдаёт общую
закреплённую ссылку `?snapshot=…`. Для нового прогноза пользователь получает
новую ссылку, заменяет URL подключения QGIS и повторно добавляет слой.
Незакреплённый адрес используется для discovery последнего состояния.

## Review и Development

Независимые Standards и Spec review выполнены относительно начального коммита.
Исправлены проверка русского JSON-текста после декодирования, зависимость теста
от кодирования snapshot и недостаточное desktop-покрытие. Существующий полный
desktop-отчёт сохраняется при совместном использовании runner-флагов.
Повторный review не выявил оставшихся замечаний.

Development подтвердил независимые модели, частичный новый расчёт без старых
полей/сроков, позднее исправление старого расчёта, полную замену сроков редакции,
реальный отказ подготовки, частичное снятие, восстановление новой редакцией,
истечение и физическую сборку мусора без отката. Identify сравнивается с явными
константами synthetic GRIB, дополняющими обязательный actual-source T5.

Обычный QGIS сохранил 280 K после перерисовки и открытия проекта; новая общая
ссылка дала 290 K, вторая модель — 275 K. После снятия доступны только
сохранившиеся 100000 Pa; прежние providers не возвращают прогноз после снятия
или истечения. Дерево проверяется через штатный диалог после замены ссылок.

Неудачные Development-попытки сохранены: ошибки типизации тестового кода,
ошибочная область provenance fixtures, отсутствие FORMAT у Identify,
повторное использование модели с уже опубликованным новым расчётом,
ожидание 400 вместо действующего 404 для отсутствующего срока и PYTHONPATH.
Первый desktop-драйвер использовал незакреплённый discovery URL; он исправлен
согласно уже согласованному уточнению №105/106. Эти результаты не являются
итоговой продуктовой приёмкой. Общий standalone mypy проверил 130 файлов.

## Итоговая приёмка

На свежем `hmc-publication-t11-w108-final1` пройдены обе фазы T11 с
`-CommonWms -PublicationUpdates` после review, без изменения runtime-входов.
Actual-source T5 проверил все 24 срока, промежуточные редакции, позднюю доставку,
исправление, отказы и сохранённых читателей. После отдельного перезапуска
подтверждены 28 редакций/28 уникальных batches и эталон 298.2274169921875 K.

Пройдены scoped/common HTTP WMS, доступ и отзыв, очередь/ожидание, ошибки,
новые сценарии №108 и заключительные снятие/истечение/GC. Старая снятая ссылка
не восстанавливается новой редакцией; доступный старый расчёт не становится
latest после физического удаления нового. Миграция реестра после GC также
проверена существующим common lifecycle.

QGIS 3.44.11: штатные карта, temporal metadata, легенда и Identify, холодная
матрица 48/48 public/org, оба CRS слоя, три CRS проекта, два размера и два срока.
Расширенный обычный диалог подтвердил все перечисленные Development-сценарии
на финальных входах, включая сохранённый проект, частичное снятие и истечение
при доступном старом расчёте. Временные слои/подключение удалены; исходный пустой
проект восстановлен. Холодные probes подтвердили очистку своих сокетов/потоков.

Полный Python suite: 142 теста, OK, 52 ожидаемых пропуска для других изолированных
стендов; три новых HTTP-теста отдельно исполнены в своих фазах. Runtime probe,
full-source mypy (130 файлов), PowerShell syntax и ссылки инструкции пройдены.
Доступ/бюджеты/retention policy не изменены; отдельные полные T8/T9/T7 не требуются.

Все 226 входов runner совпали в начале и конце. Сохранены 229 точных копий
(включая исходный GRIB, документацию и Git attributes); SHA256 копий проверены.
Шесть Docker/Compose-файлов первоначально не попали в предварительную копию:
их отдельное дополнение побайтно совпало с хешами, замороженными runner до
приёмки. Исходный архив сохранён; этот недочёт копирования и исправленная
сверка записаны отдельно. Проверенные runtime-файлы не менялись.
