# Полный каталог общего WMS — №107

15.11.2026. [Задача №107](https://github.com/stepanosokin/hmc-app-prototype/issues/107),
[спецификация №105](https://github.com/stepanosokin/hmc-app-prototype/issues/105).
Начальный коммит: `93821edb9d0f4428adce5ba1ae05706af203a9ad`.
Согласованы средний уровень, Windows/PowerShell, Docker Desktop,
GIS-шлюз, браузеры и QGIS 3.44.11-Solothurn через MCP.

## Результат

Общий каталог показывает «Гидрометцентр → модель → самостоятельные слои».
Папки не имеют `Name`; названия слоя и стиля русские, с вертикальным уровнем
или границами слоя. Единицы величины остаются в описании и легенде.
Скорость ветра доступна отдельно; внутренние U/V и направление исключены.
Настройки веб-карты не определяют состав WMS.

Имена учитывают модель, показатель, поверхности, сетку, участника и постоянную
семантику агрегации. Переименование, расчёт, редакция и меняющаяся длительность
накопления не создают новый слой. Совпадения объясняются в названии либо
останавливают подготовку. Worker сохраняет разные сетки и совместимо заменяет
старую интервальную идентичность. Identify сообщает конкретные границы интервала;
легенда без TIME относится к раннему сроку.

В «Источник и настройки» название для подключения берётся из самого XML-каталога,
включая различающие варианты. Обе кнопки копируют общий закреплённый URL;
выбор старого расчёта не превращает его в ссылку на старый прогноз.
Продукты, стили, CRS, численные значения, доступ и лимиты сохранены.

## Review

Standards и Spec независимо проверены относительно начального коммита до
единственного ticket-коммита. Исправлены совместное чтение старых/новых
интервальных полей, их замена при refresh и единицы почвенных уровней.
Дополнительно браузер проверяет фактический выбор ожидаемого показателя.
Повторный review не выявил оставшихся замечаний.
Полный suite затем выявил лишнее чтение манифестов для старого compact discovery.
Мгновенные поля теперь получают имя из сохранённой идентичности; raw metadata
читается только для старых интервалов и U/V. Три существующих регрессии каталога,
повторные types и review этого исправления пройдены.

## Проверки

Development прошёл расширенный HTTP-сценарий: несколько моделей/показателей,
две сетки, независимые константы 280/285 K, 101000 Pa и скорость 5 м/с,
накопления 3/6 ч, переименование/новый расчёт/редакция, постоянные правила,
смешанные старые/новые поля и реальный worker refresh. Неоднозначная подготовка
отклонена, прежний снимок сохранён.

Обычный диалог QGIS добавил четыре слоя двух моделей без сборки provider URI:
давление, обе сетки температуры и скорость ветра. Имена, карта, легенда и
Identify проверены. Временное подключение/слои удалены, пустой проект восстановлен.
Chrome проверил три показателя двух моделей, старый расчёт и обе точки копирования.
Отдельный штатный браузерный Development прошёл численное сравнение и отсутствие GPU.

Полные Python types: 128 файлов; TypeScript; viewer suite: 82/82;
PowerShell syntax и ссылки инструкции QGIS пройдены.
Полный Python suite без HTTP, с обязательным GRIB в `/input`: 139 тестов,
OK, 57 ожидаемых пропусков. Compact regression включает 82 редакции,
2460 исходных полей, 30 шаблонов и предел сериализации 2 МиБ.
Итоговая приёмка WMS/QGIS пройдена: полная публикация T5 и её restart-проверка,
HTTP-контракт, 48 холодных QGIS-сценариев, обычное добавление четырёх слоёв,
повторный HTTP и полный каталог после перезапуска, expiry/withdrawal/GC и
совместимость прежнего реестра. Полный Python suite с HTTP: 139 тестов,
OK, 49 ожидаемых пропусков для отдельных стендов.
Штатная матрица Chrome/Edge прошла на четырёх размерах окна, с вариантами
шрифтов/подложек, без GPU и с независимым численным сравнением.
Целевая матрица каталога прошла 32 комбинации: четыре сценария, четыре
размера окна, Chrome и Edge; обе точки копирования проверены в каждом сценарии.

Браузерные снимки содержат по 445 входов. Все 224 входа итоговой приёмки
WMS/QGIS совпали в начале и конце; каждая замороженная копия проверена по SHA256.
После браузерных проверок изменился только `publication/run-qgis.ps1`:
413 остальных входов, кроме восстановленной сборки, совпали побайтно.
Результаты браузеров привязаны к своим исходным снимкам; повторное использование
обосновано в `runner-only-change.json` и `target-driver-inputs.json`.
Целевая браузерная матрица первоначально получила 429 при параллельной загрузке
ветрового оверлея; журнал шлюза подтвердил `admission=concurrency`.
В целевом сценарии ветер выключается обычной кнопкой, что дополнительно проверяет
независимость каталога от оверлея. Лимиты не менялись. Изменился только
`checkCatalogueSettings`; исходники приложения и тело `checkSourceSettings`,
исполненное успешной обычной матрицей, совпадают побайтно. Оба снимка сохранены.
Историческая проверка прежних архивов не выполнялась.

## Попытки и очистка

Сохранены ошибки типизации новых тестов, порядок установки даты GRIB-fixture,
ошибочное ожидание stderr вместо штатного JSON worker и две ошибки порядка
действий браузерного драйвера. Отдельно зафиксированы ограничения sandbox на
дочерние процессы и занятый порт до создания стенда. Последующие проверки
устранили причины; неудачные результаты не заменены успешными.
Также сохранены полный suite с регрессией compact discovery и ошибочный запуск
suite без обязательного `/input`; правильный запуск с тем же образцом прошёл.
Заключительный T5 verifier предполагал одно поле в редакции и сопоставлял сроки
первого scoped слоя с объединением сроков всех полей. Его полный restart-проход
перенесён до многополевых fixtures; поздний restart расширенного каталога сохранён.
Изменился только порядок проверочного runner, не исходники приложения.

Полные отчёты, снимки, исходники и receipts находятся вне Git в
`HMC_EVIDENCE_ROOT/wms107/`; ссылки и SHA256 индексов — в
[индексе архивов](wms-107.archives.json). Сохранён 31 архив: все файлы первых
30 архивов (6814 файлов) независимо перепроверены; заключительный архив
`completion-precommit` проверен архиватором при копировании.

Основные результаты: `service-final3-passed`, `service-final3-inputs`,
`browser-final3-passed` (штатные браузеры), `service-final2-restart-fixture-mismatch`
(успешные целевые браузеры и сохранённый неуспешный поздний T5 verifier),
`source-freeze4-normal-browser`, `source-freeze6-target-passed`, `completion-precommit`.
Удалены и независимо проверены все 14 Docker-проектов задачи: контейнеров,
сетей и томов не осталось. Receipts сохранены в заключительном архиве.
Тестовые браузерные процессы отсутствуют; QGIS восстановлен, временное
подключение удалено. Удалены 11 каталогов приватной конфигурации стендов.
Исходные 31 файл локального кэша сборки восстановлены по хешам, протестированная
сборка сохранена в замороженных снимках. Посторонние ресурсы и live-стенд сохранены.
Проверки документации/review не создавали тестовых ресурсов.

архивирование и cleanup завершены, блокеров нет. Commit/push и закрытие №107
выполняются после записи; их фактические идентификаторы и прочитанное состояние
