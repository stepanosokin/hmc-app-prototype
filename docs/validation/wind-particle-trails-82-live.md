# Применение следов частиц к hmc-app-live

03.11.2026 пользователь отдельно поручил обновить `hmc-app-live` после
завершения исходной [задачи №82](https://github.com/stepanosokin/hmc-app-prototype/issues/82).
Эта запись дополняет [исходную приёмку](wind-particle-trails-82.md), которая
не включала применение к работающему стенду. Исторические результаты сохранены.

Применён код commit `1a277e88a107b9b2cff9823fc9de98a12f9af625` через
штатный `node viewer/build.mjs` по [инструкции администратора](../../ADMIN.md#обновление-кода-просмотрщика).
До сборки `check-viewer-runtime.mjs` обнаружил ровно два устаревших модуля:
`wind.js` и `wind-overlay.js`. После сборки все 29 модулей, полученных по HTTP
с `http://127.0.0.1:8140`, побайтово совпадают с компиляцией текущих исходников.
TypeScript/build — PASS. Старый и новый JavaScript сохранены в доказательствах.

Состояние до/после: `api`, `viewer`, `gateway`, `db`, `geoserver` работают;
адреса и каталог GRIB сохранены. Обновлены только подключённые статические
файлы; API/база/тома/контейнеры не пересоздавались. Пользовательский
`hmc-app-live` оставлен работающим по запросу.

## Прямая проверка

- Chrome/Edge: прямой `--direct-smoke` на live с реальными API, без подмены
  JavaScript или полей; по 13 проверок и 5 снимков. Проверены принадлежность
  следа частице, наличие частиц, точная идентичность U/V, плотность, пауза
  (неизменность пикселей), возобновление, кадры движения/respawn, переключение
  ветра, точечный график и управляемая память ≤128 МиБ.
- Прямая регрессия live-изолиний с `--interaction` — PASS: растр и 24 кривые
  готовы, Canvas содержит нарисованные пиксели, выключение/включение сохраняет
  выбранное поле. Просмотрены снимки live после respawn и с изолиниями.
- Полная приёмка логики удаления следа и матрица размеров/проекций приняты
  в №82. Этот rollout не заменяет и не расширяет их новыми заявлениями о FPS
  или физических устройствах.
