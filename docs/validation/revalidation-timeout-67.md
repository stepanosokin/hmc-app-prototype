# Пересчёт опубликованных полей без общего тайм-аута

Задача [#67](https://github.com/stepanosokin/hmc-app-prototype/issues/67),
начальный commit `cd96fd5f22302a4b922101e9219ea891ca7b2324`.
Пользователь сообщил об остановке пересчёта 11 редакций через 600 секунд
при записи COG и попросил убрать ограничение времени.

`publication.revalidate apply` больше не использует бюджет одной загрузки
GRIB. Операторская Node-команда также не ставит внешний таймер на 660 секунд:
`runOwned` принимает явное `null` для неограниченного ожидания. Обработчики
Ctrl+C/SIGTERM, проверка владельца и удаление временного контейнера сохранены.
Preview остаётся ограниченным 120 секундами, обычная синхронизация — своими
прежними пределами; бюджет загрузки GRIB остаётся 600 секунд. Маски, данные,
настройки хранения и атомарное переключение редакций не менялись.

Короткая регрессия до исправления воспроизвела `signal.alarm(600)` через
настоящую точку входа Python и постановку таймера в Node. После исправления
она проверяет отсутствие таймера, успешное завершение, ограниченный режим,
истечение заданного срока и отмену SIGINT, а также снятие обработчиков
и завершающую инвентаризацию контейнера. Ожидание десяти минут не требуется.

Цель поставки — исправленная команда с проверкой на изолированном стенде.
Пересчёт большого каталога `hmc-app-live` в эту приёмку не входит и не
выполнялся. После изменения исходников нужен новый файл плана: `preview`,
затем `apply` с тем же именем. См. [инструкцию](../field-nodata.md).

Проверено после review относительно начального commit:

- 19 Node-проверок управления публикациями; mypy: 107 файлов без ошибок.
- NoData: 12 тестов, все выполнены на изолированном стенде; отдельный
  операторский `preview` → `apply` завершился с `state: applied`.
- Actual-source T5: 24 срока, исправления и сохранённые читатели;
  после перезапуска проверены 28 редакций и точечное значение
  `298.2274169921875 K`. Общий набор: 103 теста, 32 ожидаемых пропуска.
- 343 входных файла заморожены до сервисной приёмки и повторно сопоставлены
  после T5; байты изменённых программ сохранены в снимках. Образ зависимостей
  `hmc-publication:nodata65` переиспользован без изменения зависимостей.
- Ссылки документации проверены. T6/T7, браузеры, QGIS и исторические архивы
  не перепроверялись: их поведение и входы не относятся к снятию общего таймера.
