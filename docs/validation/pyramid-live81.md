# Пирамида ×8 и сглаженные изолинии на hmc-app-live — №81

02.11.2026. [Задача №81](https://github.com/stepanosokin/hmc-app-prototype/issues/81).
Начальный commit: `3d8006419b4197e0de49671a005e5a9bb6a3224a`.
Принятый результат [№79](pyramid79.md)/[№80](surface80.md) перенесён в штатные
API и viewer: обычная карта получает ×8, изолинии строятся по сглаженной
поверхности. Решение и границы точности: [ADR 0012](../adr/0012-derived-display-pyramid.md).

## Результат и численная проверка

- Новый `/display/4/{2,4,8}/` создаёт производные блоки по существующему Zarr.
  Кеш процесса API ограничен 16 MiB и разделяется с исходными native-блоками;
  постоянных пирамид на диске нет. Проверки доступа, публикации и исходного
  хранилища выполняются до кеша. Native API 1–3 сохранён.
- Все 129 блоков трёх реальных полей (`t`, `prmsl`, `tp`) для ×1/×2/×4/×8
  побайтно совпали с независимым принятым JS-прототипом, включая маски и halo.
  96 исходных блоков и исходные метаданные также совпали; максимальная ошибка 0.
  Отдельный unit проверяет дробные площади, пропуски, нули и стык блоков на
  сетке 17×1031; второй — метаданные по настоящему синтетическому GRIB.
- Replay рабочего `contour-surface-worker.js` по полученным из live блокам:
  24 сценария (три поля, обзор/приближение, четыре уровня), пересечений нет;
  прежние пересечения воспроизведены независимой геометрической проверкой.
  Gaussian/B-spline сохраняют численные инварианты, Float64-геометрия не
  округляется отдельно. Это не устанавливает допуск обобщения в пикселях.
- Chrome и Edge, 1280×800, DPR 1: по шесть случаев на браузер, три поля,
  четыре проекции, изменение срока, toggle изолиний; реальные запросы U/V ×8,
  видимые движущиеся частицы, графики и 30 канонических значений точки на браузер.
  Ряд ветра сверён с исходными U/V и исходными центрами ячеек повёрнутой сетки.
  Управляемая память до 70 988 748 байт (<128 MiB). Загрузка поля 252–337 ms,
  построение изолиний 233–466 ms; это наблюдения live, не сравнение с диском.
  Просмотрены снимки температуры Chrome и давления Edge. Физические устройства
  и полная историческая приёмка прежних задач в эту проверку не входят.

## Сервисы, развёртывание и ограничения

Development T5 и новый gateway-тест прошли; финальный свежий T5 после review:
публикация/редакции/restart, mypy 93 файла, suite 122 теста (37 условно пропущены),
отдельный новый HTTP-тест прошёл. Он доказывает warm metadata/block cache,
изменение префикса организации, отзыв ключа до тёплого ответа, пропажу исходного
chunk, истечение публикации и восстановление. Отдельный полный T6 прошёл:
семь recovery-сценариев, detached delivery, restart, legacy publication,
mypy 93 файла, suite 122 теста (37 условно пропущены), фиксация входов и образа.
Viewer: 71 Node-тест и TypeScript check прошли.

На `hmc-app-live` пересобран viewer и перезапущены только существующие
api/gateway/viewer. 29 обслуживаемых JS-модулей совпадают с компиляцией исходников.
Все пять ID контейнеров, образы и наборы монтирований сохранены; DB/GeoServer
не перезапускались. SHA256 компактного каталога до/после:
`16e772f609be607521274afd8fee3a72e269b491946b6b691c2c1cfc874afe75`.
GRIB не загружались повторно, Zarr/COG и редакции не пересчитывались.
Резервная копия прежней сборки и серверных модулей сохранена.

Review Standards: 0 нарушений и существенных эвристических замечаний.
Spec: исправлен расчёт координат исходной ячейки ветра через `source_grid`;
фактический ряд проверен в обоих браузерах. Review проверочных программ усилил
проверки полного ряда ветра, реальной отрисовки и запросов обеих компонент ×8.

Неуспешные попытки сохранены: mypy потребовал аннотацию списка; первый новый
HTTP-тест ожидал скрытый шлюзом заголовок вместо внутренних метрик; `npm.cmd`
отсутствует на этом хосте (использован `npm.exe`); первый readback после restart
получил сетевой сбой одного модуля. Повторные проверки прошли. Docker inspect
сопоставлялся как набор монтирований, поскольку порядок массива меняется.
Первый Chrome завершился с HTTP 429: учёт подтвердил отклонение на admission,
активные запросы затем отсутствовали. Повторный полный Chrome прошёл на тех же
входах без изменения лимитов; Edge запускался последовательно.
