Пользователь подтвердил восемь правил и итоговое понимание: последний reference time, сразу опубликованная часть без смешивания, целостное переключение модели, закрепление расчёта/редакции в QGIS до явного обновления и повторного добавления, отсутствие возврата к старым расчётам/редакциям, ранний срок по умолчанию и точный явный TIME.
