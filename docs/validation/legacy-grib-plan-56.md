# Отдельный план снятия старых GRIB-публикаций — №56

26.10.2026. База: `b4cb4ff896ac9b5f103821b5169d8c7a80495a6f`.
Задача: [№56](https://github.com/stepanosokin/hmc-app-prototype/issues/56).
Пользователь запросил подготовку плана и инструкцию, **без применения на live**.

Явный флаг `--include-unlocated` включает публикации с известным безопасным
именем без исходного каталога. Режим связан с целевым стендом, папкой и планом;
применение без того же флага отклоняется. Известный другой каталог,
неизвестное имя и синтетические источники остаются вне области. Обычный режим
прежний. Манифесты партий не переписываются. Подтверждённое исключение записано
в [ADR 0007](../adr/0007-grib-publication-withdrawal.md), команды — в
[инструкции](../grib-sync.md#отдельный-план-для-старых-публикаций-без-каталога).

Для множества исторических замен полная проверка общей неизменяемой партии
выполняется один раз в пределах операции; повторно используется только
проверенный граф её файлов. Атомарность, повторные проверки актуальности,
хронология, сроки хранения и обработка неопределённого COMMIT сохранены.
Лимит применения увеличен до 30 минут; просмотр ограничен двумя минутами.
