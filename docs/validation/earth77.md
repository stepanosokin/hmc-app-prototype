## Технологии визуализации

MapLibre GL JS управляет картой. WebGL 2 рисует числовые поля и применяет
общую цветовую таблицу. Canvas 2D рисует движущиеся частицы и затухающие следы.
Python/NumPy вычисляет скорость из U/V; GeoServer отдаёт стандартные WMS-карты.
