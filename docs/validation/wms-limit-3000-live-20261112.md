# GetMap 3000×3000 в hmc-app-live

Пользователь поручил установить предел 3000 и применить его к hmc-app-live,
явно запретив любые тесты. Среда: локальные Windows/PowerShell и Docker Desktop.
Исходный commit: `3cca8f503d1f395ab39d5cccf7a3edcca1430f08`.

Изменены максимальный размер GetMap, default/max `Limits.dimension`, запасное
значение dimension в API и идентификатор WMS-профиля ETag. Gateway и capabilities
используют общий предел через существующую логику. Сохранённых строк в
`access.policies` у live нет: применяются новые defaults, миграция политик
не потребовалась. Ограничение Identify осталось 16384, concurrency, таймауты
и предел тела ответа 4 МиБ не менялись.

Предел памяти одного WMS-запроса GeoServer увеличен с 16384 до 65536 KiB:
один несжатый RGBA-буфер 3000×3000 занимает около 34,3 МиБ. Это ограничение
памяти рендеринга, а не увеличение concurrency или лимита PNG-ответа.
Операторский вызов прочитал прежнее значение, применил новое и считал его
обратно; maxRenderingTime остался 20 секунд.

Код publication подключён в контейнеры из рабочей папки. Перезапущены только
API и gateway; сборка образа не требовалась. Образ остался
`sha256:9b1a3b8568df778ee2262fb198819550055e45f9e2f2674e726e8ca9a2ea0c47`.
Операционное чтение конфигурации gateway вернуло max_map_size=3000 и
default_dimension=3000. Все пять live-служб имеют состояние running,
Docker health БД и GeoServer — healthy. Постоянные тома, публикации и
пользовательский QGIS не изменялись. Одноразовый worker настройки удалён
через `--rm`; именованный временный контейнер отсутствует.

Тесты, проверки типов/линтеры/документационные проверочные программы,
T5/T9/T11, HTTP GetMap и QGIS-рендеры **не запускались**. Изменения просмотрены
по diff; ожидаемые значения существующих тестов обновлены без их запуска.
Чтение применённых настроек и состояния контейнеров — операционная квитанция,
не функциональная приёмка. Полнота изображения, 4K, нагрузка и дополнительный
пробел покрытия из [диагностики](qgis-wms-server-compatibility-20261112.md)
не подтверждены этим обновлением. Не заявляется исправление всех случаев QGIS.

Объём запроса выполнен: лимит изменён и применён. Новая issue не создавалась,
прежние issue не менялись. Тестовые ресурсы не создавались; сохранён только
пользовательский hmc-app-live и общие образы/кеши.

Операционные журналы, конфигурация до/после и snapshot изменённых файлов
архивированы: `wms-limit-3000/20261112-live` относительно HMC_EVIDENCE_ROOT,
16 файлов. SHA256 `archive-index.json`:
`a5495ae5c225b47382faa1885d9fd874c3d0b00617e4ca6e28c7a8a1161e02ad`.
Архивирование проверило целостность копий; исторические проверки не запускались.
