# NoData выбранных показателей и легенда удельной влажности

Задача [#69](https://github.com/stepanosokin/hmc-app-prototype/issues/69),
начальный commit `fc48d682293928fc0c87ede7a573928efef027ae`.
Пользователь подтвердил настоящий NoData для точных нулей поверхностного
и морского давления, относительной влажности, удельной влажности у поверхности
и на 2 м, порывов и видимости. Для почвы добавлен фактический код 2.3.18
к правилу ≤ 0 K. Единицы и уровни ограничивают правила; остальные нули
сохраняют прежнюю численную допустимость и оформление.

Политика `field-validity/3` использует существующую общую маску и пересчёт
неизменяемых публикаций. Удельная влажность остаётся в кг/кг; только легенда
округляется до трёх значащих цифр. Точки, графики и численные данные
этим форматированием не меняются. Решение записано в ADR-0009.

## Проверки

- Node: 13 затронутых проверок, без ошибок; NoData-preflight и viewer-fixture
  preflight прошли. Эти проверки не создают постоянных тестовых ресурсов.
- mypy: 108 файлов без ошибок. Изолированный NoData: 18 тестов без пропусков,
  проверены причины пропусков, точные ±0, малые ненулевые и отрицательные
  значения, статистика, COG-маска, точка, GIS Identify и WMS. Проверены
  сохранение нулей других уровней/единиц/показателей и операторский apply.
- Chrome 155.0.8059.85 и Edge 156.0.4314.42: по 24 сценария (шесть полей
  на 1440×900, 390×844, 360×740, 640×360). Подтверждены NoData и допустимые
  нули на GPU, подписи легенды обеих удельных влажностей и исходные кг/кг.
  Мобильные размеры эмулированы; физические устройства не проверялись.
- T5 на одном эталонном GRIB: сроки, исправления и прежние читатели прошли
  за 182,447 с; после перезапуска доступны 28 редакций, контрольная точка
  298,2274169921875 K. Общий набор: 109 тестов за 68,709 с,
  34 ожидаемых пропуска для других сервисных режимов.
- 344 runtime-входа сверены после приёмки; все 344 файла в каждой из двух
  внешних копий независимо сверены с замороженными размерами и SHA256.
- Обновление live выполнено; результаты приведены ниже. Полный аудит всех реальных наборов
  намеренно не выполняется: выбраны восемь затронутых полей и четыре
  исключения (осадки, снег, облачность, компонента ветра).

## Обновление hmc-app-live

Штатный apply успешно заменил 11 редакций, пересобрав 324 уникальных поля
примерно за 30 минут. Job `efe04ced-aa54-4ded-be2b-59936dda03f9`, план
`b67041cba778d2d3ca17b5febd965df8209bc1d5231c941c74a1fb6b40e0c393`.
Состав 1674 выборок сохранён; повторный preview пуст, старая ссылка даёт 410.
Сборка main.js, выдаваемая live, совпала с принятой по SHA256; все 344 входа
снова сверены. Исходные GRIB повторно не декодировались.

Выборка: sot, sp, prmsl, 2r, q, 2sh, max_i10fg, vis и исключения tp, sde,
ccl, 10u, по одному сроку. У всех 12 совпали исходные численные хеши
и счётчики исходных пропусков; маски причин и native COG независимо сверены
с согласованными правилами. В первых восьми нулевые точки возвращают
`native_nodata/rejected_value`: 245945 отбраковок в каждом поле, кроме
порывов (258534). У осадков, снега и облачности нули по-прежнему дают 0;
в выбранном поле U точных нулей нет, допустимость нуля покрыта синтетической
регрессией. Доступный контрольный GRIB в data/grib сохранён по размеру/SHA256.

Первая попытка одноразового аудита неверно передавала WGS84 без `crs`:
API ожидаемо трактовал координаты как исходную сетку. Дифференциальная
проверка одной ячейки подтвердила правильный NoData в native и явном CRS84.
Исправлен только вспомогательный аудит. Повторный численный аудит 12 полей
прошёл, затем отдельный Node HTTP-запрос получил разрыв соединения.
Точная причина разрыва не установлена; API не перезапускался, OOM отсутствовал.
Оставшиеся HTTP-проверки прошли на отдельных соединениях. Обе попытки и
диагностика сохранены; runtime-код после заморозки не менялся.

Три изолированных проекта удалены; независимый контроль подтвердил ноль
контейнеров, сетей и томов каждого. Браузерные процессы и профили удалены.
Контейнер пересчёта завершился и удалён; сохранены ровно пять работающих
служб hmc-app-live по запросу пользователя. Исходники, отчёты и общие кеши
сохранены. Историческая проверка архивов не выполнялась.
