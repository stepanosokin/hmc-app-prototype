# Значки панели полей

Автор: Magnific (ранее Freepik), стиль Basic Straight Flat.
PNG загружены с Flaticon в размере 128×128; в интерфейсе показаны 28×28.
Приложение использует локальные копии из `/vendor/field-icons/`;
`viewer/prepare.mjs` переносит их из исходников при подготовке ресурсов.
Размеры и SHA256 зафиксированы в [manifest.json](manifest.json) и проверяются перед копированием.
Ссылка на автора находится в панели «Источник и настройки».

| Файл | Английский запрос / назначение | Источник |
| --- | --- | --- |
| temperature.png | Temperature / Heat | [Heat 1536260](https://www.magnific.com/icon/heat_1536260) |
| pressure.png | Pressure / Gauge; шкала прибора | [Speedometer 4453819](https://www.freepik.es/icono/velocimetro_4453819) |
| humidity.png | Humidity | [Humidity 4015433](https://www.magnific.com/icon/humidity_4015433) |
| wind.png | Wind | [Wind 4487658](https://www.magnific.com/icon/wind_4487658) |
| precipitation.png | Precipitation / Rain | [Rain 2339334](https://www.magnific.com/icon/rain_2339334) |
| cloud.png | Cloud | [Clouds 1634355](https://www.magnific.com/es/icono/nubes_1634355) |
| snow.png | Snow / Snow flake | [Snow flake 1585791](https://www.magnific.com/icon/snow-flake_1585791) |
| visibility.png | Visibility / Eye | [Eye 8392817](https://www.magnific.com/icon/eye_8392817) |

Бесплатные форматы требуют указания автора: [правила Magnific](https://www.magnific.com/icons),
[автор на Flaticon](https://www.flaticon.com/authors/magnific).
Файлы используются как элементы управления внутри приложения.
Неизвестные показатели обозначаются нейтральным многоточием;
метки уровней и разновидностей формируются из метаданных поля.
